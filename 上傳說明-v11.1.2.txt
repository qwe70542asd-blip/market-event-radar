市場事件雷達 v11.1.2 上傳步驟

1. 解壓縮 market-event-radar-v11.1.2-complete.zip。
2. 打開解壓後的資料夾，將「內部全部檔案與資料夾」上傳到 GitHub 倉庫根目錄。
3. 覆蓋同名檔案並 Commit changes。
4. 不要刪除 live-data 分支。
5. GitHub → Actions 依序手動執行：
   - Update v11.1.2 daily data
   - Update v11.1.2 Taiwan market
   - Update v11.1.2 multi-source news
6. 等待 Pages 部署完成後按 Ctrl + F5。

本版第一次執行 daily data 後才會補齊：
- 全部上市／上櫃股票財務分析與產業排名
- ETF 經理人、發行公司、標的指數、成立／上市日期與保管機構

第一次執行 multi-source news 後才會套用：
- 同事件合併
- 排名模板收斂
- 不同媒體交錯
- 上市／上櫃公司重大訊息

data/ 是離線備援，live-data 是自動更新資料層。
