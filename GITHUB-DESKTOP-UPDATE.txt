市場事件雷達 v11.4.41 — 正確性強化 / 來源健康修正版

覆蓋方式
1. 解壓縮 ZIP。
2. 把 ZIP 內「所有根目錄內容」直接覆蓋本機 market-event-radar repository；不要多包一層資料夾。
3. 雙擊根目錄 CLEAN-REPO.cmd。因為單純覆蓋不會刪除舊檔，這一步會清掉 v11.4.40 舊 verifier/tests、舊 deletion manifest、apply_v11_4_36.py 與意外巢狀 repository。
4. GitHub Desktop 檢查變更後 Commit to main，再 Push origin。
5. 建議 commit：market-event-radar-v11.4.41-correctness-hardening

這版主要修正
- TPEx 公司成立日期：支援 ROC compact date，並拒絕未來日期與「成立日晚於掛牌日」的 schema 誤配；stock-basics 發布前會 fail-closed 驗證。
- TPEx 股利計畫：依 live diagnostic 實際 schema，正確接受「股東會日期配盈餘/待彌補虧損(元)」這個歷史欄名中的 ROC 日期。
- TWSE 當沖市場彙總：從官方 TWTB4U 個股列精確加總成交股數、買進金額、賣出金額；不自行估算百分比。
- TPEx 法人金額：擴充中英文欄位與 label schema 容錯；官方來源取不到時維持 —，不以張數×股價推估。
- Data Verification：PE/PB/殖利率維持可比對；ROE/EPS/財務比率若跨來源報表期間未證明相同，不再誤標 conflict。
- 個股頁指標可信度：改用該指標自己的 verification status，不再被整組 metrics 狀態污染。
- MOPS 歷史股利：大量來源失敗時開啟短暫 circuit breaker，避免每輪重複打 20 檔；錯誤改為摘要＋樣本。
- 新聞來源健康：直接來源 403、但歷史 fallback 成功時標示 degraded，不再顯示 health=ok。
- PWA：network-first 遇 HTTP 4xx/5xx 也會先找 cache fallback，不只處理斷線 exception。
- Diagnose artifact：actions/upload-artifact 升到 Node 24 相容 major。
