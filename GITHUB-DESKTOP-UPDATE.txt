本版核心修正
- 移除首頁 4.5 秒先放棄、live data 晚到卻永遠停在空 fallback 的競速問題。
- 台股行情、法人、全球行情、事件、新聞、資產、股利各自獨立載入；哪個先到就先更新自己的區塊。
- 今日台股狀態新增獨立 renderTaiwanStatus()，行情與法人晚到都會重新 render；市場廣度、外資方向、成交動能不再卡在第一次 seed 狀態。
- 台股 freshness 只看 tw-market 自己的 updated_at，不再混用全球市場時間。
- 台股狀態 footer 改顯示「行情時間 · 籌碼時間」，不再錯接事件月曆 updated_at。
- 新聞改為 12 個來源逐一完成就逐一顯示；單一新聞來源慢/壞不會讓整個精選區或新聞頁保持空白。
- 事件與新聞解耦；事件頁先顯示事件，相關新聞晚到再補。
- high-impact corporate 事件可以進首頁精選重大資訊，不再只接受 event_group=major。
- 台股頁、法人頁、投資組合頁、資料狀態頁改成 progressive render，附加來源不再阻塞核心資料。
- GitHub live loader 改成 hedged mirrors：Raw 先跑，真的慢才啟動 CDN/API 備援；成功後不再發出後續多餘 mirror 請求。
- 所有可用 live channel 以 IndexedDB 保存 last-known-good；寫入改成背景動作，不阻塞畫面更新。
- Service Worker 對 /data/*.json 正規化 cache key，移除 ?t= / ?_= cache-busting，HTTP 4xx/5xx 或斷線時能找到上一份快取。
- Browser smoke 新增 delayed-live regression：故意讓 tw-market 晚 5.2 秒、chips/events/news 不同時間才回來，最後必須補回 1,244 漲/743 跌、外資買超、量能正常與重大資訊。
