市場事件雷達 v11.4.21 覆蓋方式

1. GitHub Desktop 選擇 market-event-radar repository。
2. Repository → Show in Explorer。
3. 解壓 ZIP，將全部檔案與資料夾複製到 repository 根目錄。
4. 覆蓋同名檔案，但不要刪除 .git。
5. Summary 填 Update to v11.4.21。
6. Commit to main，再按 Push origin。
7. 等待 global market、event calendar、stock basics 與新聞 Actions 完成。
8. 頁面若仍顯示舊版，重新整理；v11.4.21 Service Worker 會清除舊快取。

重要：GitHub Actions 只能作五分鐘級備援。要達成盤中每分鐘檢查，請依 docs/V11.4.21-live-market.md 部署 edge/market-live-worker.js，並把 Worker 網址填入 assets/runtime-config.js。
