Market Event Radar v11.4.47 update steps

1. Close the website tab if it is open.
2. Extract this ZIP directly over the root of your existing market-event-radar repository.
3. Double-click CLEAN-REPO.cmd once.
4. Open GitHub Desktop and verify the changed files include:
   - index.html
   - assets/runtime-config.js
   - assets/v11.4.47-overrides.css
   - edge/market-live-worker.js
   - edge/wrangler.jsonc.example
   - scripts/production_readiness.py
   - scripts/validate_public_data.py
   - .github/workflows/deploy-live-market-worker.yml
   - .github/workflows/release-verification.yml
   - service-worker.js
   - VERSION.json
   - deletion of old DELETION-MANIFEST-v*.txt files
5. Commit and Push.
6. In GitHub Actions, wait for Verify v11.4.47 stable app release and Deploy v11.4.47 live market worker.
7. The Worker deployment no longer needs or publishes a live-runtime branch. The browser validates the fixed allowlisted workers.dev endpoint directly through /health.

Expected behavioral changes:
- Calendar appears above the six-index K-line panel.
- Four square quick-navigation buttons float on the left on desktop.
- The selected major-information block is shorter.
- Worker KV cache uses schema-versioned keys, so old v11.4.45/v11.4.46 snapshots cannot poison the deployment.
- Rate limiting is per requester + route rather than one global route bucket.
- Taiwan turnover history may be newer than retained quote data without failing the whole Taiwan-market publish.
