市場事件雷達 v11.4.19 覆蓋方式

1. 在 GitHub Desktop 選擇 market-event-radar repository。
2. 點 Repository → Show in Explorer。
3. 解壓本 ZIP，將 ZIP 內全部檔案與資料夾複製到 repository 根目錄。
4. 選擇覆蓋同名檔案，不要刪除 .git 資料夾。
5. 回到 GitHub Desktop，Summary 填 Update to v11.4.19。
6. Commit to main，再按 Push origin。
7. 推送後等待 GitHub Actions 更新市場、新聞與事件資料。
8. 若頁面仍顯示舊版，重新整理一次；v11.4.19 Service Worker 會清除舊快取。

本版把首頁「我的資產總覽」改成 3 欄 × 2 列，六項數據會平均使用整個面板空間；手機版為 2 欄 × 3 列。公開「資料覆蓋」入口仍維持移除。
