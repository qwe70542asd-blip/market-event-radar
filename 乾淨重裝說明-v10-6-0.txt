市場事件雷達 v10.6.0｜首頁完整整合乾淨版

這一版不是覆蓋更新包。
請用完整乾淨重裝，避免 v10.4／v10.5 舊檔、舊 Workflow 與新檔混用。

一、先解除目前合併狀態
1. GitHub Desktop 若顯示 Resolve conflicts，先按 Abort merge。
2. 按 Fetch origin。
3. 若出現 Pull origin，先完成 Pull。
4. 確認畫面上不再顯示正在 Merge。

二、清除舊網站
1. GitHub Desktop：Repository → Show in Explorer。
2. 打開 market-event-radar 專案資料夾。
3. Windows 檔案總管開啟「顯示隱藏的項目」。
4. 只保留隱藏的 .git 資料夾。
5. 其他網站檔案與資料夾全部刪除，包括舊的 .github、assets、data、scripts、HTML 與舊說明檔。
6. 不要刪除 .git，否則 GitHub Desktop 會失去專案紀錄。

三、放入 v10.6.0
1. 將本資料夾內的全部內容複製到原本 market-event-radar 根目錄。
2. 根目錄應直接看到：
   index.html
   assets
   data
   scripts
   .github
3. 不要再多包一層 market-event-radar-v10-6-0-integrated-clean 資料夾。

四、提交網站程式
GitHub Desktop Summary：
Clean integrated market homepage v10.6.0

依序按：
Commit to main
Push origin

五、建立獨立即時資料分支
1. 開啟 GitHub 網站 → Actions。
2. 選擇「Update v10.6.0 integrated live data」。
3. 按 Run workflow。
4. mode 選 all。
5. 等待綠色勾勾完成。

Action 第一次執行會自動建立 live-data 分支。
往後行情、新聞、公告、事件與法人資料只更新 live-data，不再自動修改 main。
這樣 GitHub Desktop 更新網站程式時，不會再和排程資料檔發生 market-snapshot.json 等合併衝突。
