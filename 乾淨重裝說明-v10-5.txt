全球市場即時雷達 v10.5.0｜乾淨重裝版

這不是覆蓋更新包。本版本只提供完整乾淨網站。

本版首頁「我的投資組合」：
- 移除大型教學與新聞／事件卡片。
- 每個持有或追蹤標的各自顯示：名稱、代碼、目前價格、漲跌幅、迷你走勢圖、前收、資料時間與來源。
- 網頁開啟時抓公開行情；頁面保持開啟時每 30 秒重新整理。
- 休市、週末、盤後或即時來源暫時不可用時，顯示前次收盤或上一次成功資料。
- 右側「前往個人頁面」可進入 portfolio.html 管理投資組合。
- 沒有投資標的時只顯示一條精簡入口，不再占用大面積。

行情說明：
- 台股、美股、ETF：使用公開行情端點進行最佳努力更新。
- 虛擬貨幣：公開行情端點，失敗時使用 CoinGecko 備援。
- 免費公開來源可能延遲、限流或暫時中斷；畫面會顯示「盤中／延遲、前次收盤、上次成功資料」，不會把延遲資料假裝成交易所即時報價。

乾淨重裝步驟：
1. 在 GitHub Desktop 選 Repository → Show in Explorer。
2. 關閉網站頁面。
3. 在 market-event-radar 資料夾內刪除所有舊檔案與資料夾，但不要刪除隱藏的 .git 資料夾。
4. 解壓縮本 ZIP，把 market-event-radar-v10-5-clean 資料夾「裡面的全部內容」複製到原本 market-event-radar 根目錄。
5. GitHub Desktop 會同時顯示大量 Deleted 與 Added/Modified，這是正常的乾淨重建。
6. Summary 輸入：Clean rebuild portfolio live quotes v10.5.0
7. Commit to main → Push origin。
8. GitHub Pages 部署完成後，按 Ctrl+F5。

注意：
- 不要把外層 market-event-radar-v10-5-clean 資料夾整個再包進專案，index.html 必須直接位於 market-event-radar 根目錄。
- 瀏覽器 localStorage 裡原本的投資組合不會因刪除網站檔案而消失；除非你另外清除該網站的瀏覽資料。
