# v11.4.30 Release Audit

## 本版阻擋項目

- JavaScript / Python 語法必須通過。
- 全部既有自動測試必須通過。
- 新增日期提醒完整性測試：歷史回補不得算新日期、週期性事件不得誤算改期、真正未來改期仍需保留。
- 首頁月曆啟動必須具備 timeout fallback 與 live-events 完成後的二次刷新。
- Service Worker cache namespace 必須升級，避免手機仍執行 v11.4.29 首頁程式。

## 部署後非阻擋驗證

- 15 分鐘 K 線屬部署後線上來源驗證，若 Worker／來源尚不可用必須維持非阻擋狀態，且不得偽造 K 棒。
- Push 後等待 `Update v11.4.30 event calendar and announced dates` 至少成功一次，讓 `live-events` 以 strict-v11.4.30 規則重建今日日期提醒。
- 若來源 parser 大幅變動而觸發 surge guard，首頁應顯示 0 或少量可信日期，而不是一次列出數百筆。
