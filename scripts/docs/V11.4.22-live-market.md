# v11.4.22 即時行情部署

## 未部署 Worker

- 首頁會讀取 `live-global-market` 分支的 `market-snapshot.json` 與 `market-kline.json`。
- GitHub Actions 約每 5 分鐘排程一次，但 GitHub 不保證準點。
- 網頁每分鐘檢查資料，不代表後端每分鐘一定產生新資料。

## 部署 Worker

1. 使用 `edge/market-live-worker.js` 建立 Cloudflare Worker。
2. 依 `edge/wrangler.toml.example` 設定 KV 與排程。
3. 將部署後的 HTTPS 網址填入：

```js
window.MR_RUNTIME={
  liveMarketEndpoint:"https://你的-worker.workers.dev"
};
```

4. 重新 Commit、Push。
5. 在瀏覽器開發者工具確認 `/snapshot` 與 `/kline` 回傳成功。

## 資料規則

- 最新價、漲跌與 OHLC 必須屬於同一交易日。
- 盤中最新價必須介於當日最高與最低之間。
- 超過允許時間未更新時標示延遲。
- 4 小時 K 不跨交易日或午休。
- 來源衝突時保留上一筆已驗證資料。
