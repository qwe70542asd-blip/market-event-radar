# 市場事件雷達 v11.4.30

v11.4.30 以 v11.4.29 完整版為母版，這次只針對首頁月曆卡住與「今日新公布日期」誤判做整合修正，既有台股、法人籌碼、動態產業龍頭、新聞、資產總覽與 K 線功能全部保留。

## 本版重點

- 月曆啟動改成非阻擋：行情、新聞或 GitHub live branch 變慢時，不再讓月曆永久停在「讀取中」。
- `live-events` 尚未完成時先顯示內建事件 seed；線上資料到達後原地刷新，不必重新整理頁面。
- 「今日新公布日期」新增雙層完整性檢查：後端產生器 + 前端顯示端。
- 歷史回補資料不再算成今天新公布。
- 週期性同名事件的上一期已發生時，下一期不再誤判成「日期異動」。
- 真正尚未發生的事件若官方日期改變，仍會保留原日期與新日期。
- 公司重大訊息只有明確公告未來日期時才進日期提醒；普通財報公告本身不再混入。
- 單一來源若因 parser 或 tracking-key 改版一次冒出大量「新日期」，會自動當作基準更新並抑制通知洪水。
- Service Worker、HTML cache busting、GitHub Actions 與資料 metadata 全部升級至 v11.4.30。

## 覆蓋部署

1. 解壓縮 ZIP。
2. 將包內全部檔案覆蓋 repository 根目錄，保留 `.git`。
3. GitHub Desktop Commit：`market-event-radar-v11.4.30`。
4. Push origin。
5. 等待 `Verify v11.4.30 app release` 與 `Update v11.4.30 event calendar and announced dates` 完成。
6. 手機若仍看到舊畫面，關閉舊分頁後重新開站；新版 Service Worker 會清掉 v11.4.29 cache。

## 線上資料注意

Push 後事件工作流程第一次成功執行，才會把 `live-events` 分支用新的 `strict-v11.4.30` 規則重建。即使該工作流程尚未完成，v11.4.30 前端也會先過濾舊資料中的歷史回補與不合理改期，避免再次出現數百筆假日期提醒。

15 分鐘 K 線仍屬部署後非阻擋驗證；Worker／來源不可用時不得偽造 K 棒。
