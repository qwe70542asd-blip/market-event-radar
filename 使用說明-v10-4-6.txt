全球市場即時雷達 v10.4.6｜法人與籌碼分析試作版

修正原因
首頁「上市外資／投信／自營商」原本直接連到 TWSE JSON API，因此瀏覽器只會顯示原始 JSON 文字。

新版行為
- 上市外資、投信、自營商卡片改連到站內 institutional.html。
- 上櫃三大法人暫時保留官方頁，下一階段再補完整上櫃歷史。
- 法人頁可切換：外資、投信、自營商、三大法人。
- 期間可切換：5 日、20 日、60 日、全部。
- 顯示每日買賣超、累積趨勢、每週買賣超、買進與賣出金額。
- 顯示最近交易日、近 5 日、近 20 日、連買連賣與買賣比。
- 顯示 T86 官方個股買超與賣超前 10。
- 顯示每日明細表。

資料來源
- BFI82U：市場三大法人買進、賣出與買賣超金額。
- T86：各股票外資、投信、自營商與三大法人買賣超股數。

個別大型外資券商
摩根士丹利、美林、摩根大通、瑞銀、高盛、花旗等券商分點數字不在免費 BFI82U／T86 報表內。
證交所券商分點買賣日報屬授權資料商品，因此本版不會用推測數字冒充。

第一次使用
上傳後執行：
Actions → Update v10.4.6 institutional analytics → Run workflow

Action 會抓取約 3 個月的交易日資料並建立完整圖表；安裝包先放入 7/8、7/9、7/31 三個官方日期供版面測試。
