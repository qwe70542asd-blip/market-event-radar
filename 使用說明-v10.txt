全球市場即時雷達 v10.0 第一版

本版重點
1. 修正「明明新聞已抓到，首頁仍顯示抓不到」：
   - 新聞 JSON 採 no-store 即時讀取。
   - Service Worker 不再把新聞資料永久卡在舊快取。
   - 網路失敗時依序使用上次成功資料、內建新聞來源入口。
   - 首頁顯示「即時資料／上次成功資料／備援來源」，不再只顯示空白。

2. 新增個人投資組合：
   - 可手動加入股票、ETF、基金。
   - 數量與成本不是必填。
   - 首頁優先顯示與持有／追蹤標的相關的新聞與事件。
   - 基金可選投資主題：美國科技、日本股票、債券、新興市場等。

3. 新增 portfolio.html：
   - 集中管理股票、ETF、基金。
   - 顯示個人化新聞。
   - 第一版資料存於瀏覽器 localStorage。

4. 新聞抓取改善：
   - 台灣來源使用 zh-TW/TW 搜尋。
   - Reuters、CNBC、Nikkei、White House 改用 en-US/US 搜尋。
   - 新增 PMI／ISM、基金與 ETF、白宮政策來源。
   - 單一來源失敗時保留該來源上次成功內容。
   - 來源抓到 0 筆會標示 empty/stale，不再錯誤顯示 ok。
   - GitHub Actions push 增加三次重試。

目前限制
- 股票與基金仍採手動輸入，尚未接完整四國股票主檔。
- 個人化採名稱、代碼、地區與主題關鍵字配對；後續會升級為正式資產資料庫與供應鏈關聯。
- Google 跨裝置同步仍需設定 Firebase。
