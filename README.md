# 市場事件雷達 v11.4.15

本版沿用完整專案結構，保留資料更新腳本、GitHub Actions、雙模式事件月曆、台股排行、法人籌碼、ETF、個股頁面與投資組合功能。

## v11.4.15 本次重點

### 新聞圖片不再留白

- 原新聞有圖片時優先顯示原圖。
- 原圖網址失效、跨站阻擋或載入失敗時，立即切換到相關主題的本地配圖。
- 科技、財報、利率、政策、地緣政治、原物料、總經、全球市場、台股與個股都有對應配圖。
- 首頁、財經新聞頁與個股相關新聞統一使用同一套備援機制。

### 股票基本資料 90–100%

- 新增獨立 `stock-basics` 資料通道。
- 以 TWSE／TPEx／MOPS 官方公司主檔為核心，Yahoo 股市僅補顯示欄位與參考財務資料。
- 股票基本資料完整度與進階財報完整度分開計算，不再因歷史財報尚未抓滿而把基本資料顯示成低完成度。
- 資料範圍改為全部 TWSE 上市與 TPEx 上櫃股票，不再限於投資組合或少數追蹤標的；官方主檔會一次建立全市場基本資料。
- 個股頁新增基本資料完整度標記，並整合公司名稱、產業、市場、幣別、官方來源與 Yahoo 參考頁。

### 首頁與月曆版型保留

- 「我的資產總覽」下方保留大盤 K 線與關鍵資訊。
- 「今日新公布日期」位於雙模式月曆下方。
- 首頁重大資訊維持大圖、標題與一行摘要。
- 市場事件日曆與股利股息日曆可切換並記住選擇。

## 部署

1. 解壓縮 ZIP。
2. 將解壓後資料夾內的全部內容複製到 GitHub Desktop 顯示的 repository 根目錄。
3. 覆蓋同名檔案，但不要刪除 `.git` 資料夾。
4. Commit 訊息可填 `Update to v11.4.15`。
5. Push origin。

首次推送後可在 GitHub Actions 手動執行 `Update v11.4.15 stock basics`；該流程會抓取全部上市櫃公司官方主檔，再逐批補 Yahoo 顯示欄位。瀏覽器端也有官方 API 備援，避免 live branch 尚未更新時只看到少數股票。

## 資料原則

- 官方資料優先。
- 第三方資料只補空白欄位，並保留來源標示。
- 基本資料完整度與進階財務資料分開呈現。
- 不用推測數值把進階財報硬補成完整。
- 所有內容僅供市場觀察，不構成投資建議。
