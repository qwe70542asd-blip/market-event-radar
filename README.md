# 市場事件雷達 v11.4.9

本版延續事件月曆主軸，集中修正新聞無圖大空板，並新增 ETF 多來源補全與股票財務計算通道。

## 新聞圖片

- 只使用 RSS、新聞列表、`og:image`、Twitter Card、JSON-LD 或文章內有效圖片。
- 主新聞優先選擇有原始圖片的重大新聞。
- 全部重大新聞都沒有圖片時，自動改成緊湊文字主卡，不保留大型空白圖片區。
- 側邊與一般新聞沒有圖片時改為純文字卡。
- 不使用 AI 生圖，不需要圖片 API 或額度。

## ETF 多來源補全

新增獨立 `live-etf-details` 通道，分批讀取：

1. TWSE ETF e添富官方資料。
2. MoneyDJ ETF 基本資料、淨值、配息、持股與產業配置。
3. HiStock 主動式 ETF 觀測資料。
4. Yahoo ETF 資料作為既有補充來源。

可補入發行投信、經理人、追蹤指數、規模、受益人數、淨值、折溢價、配息、持股股數、權重、持股資料日期與產業配置。官方資料存在時仍以官方為主，第三方資料只補空白欄位。

## 股票財務補全

Yahoo 詳細資料通道新增：

- 最近 20 季營收、毛利、營業利益、淨利、資產、負債、權益與現金流。
- 基本／稀釋 EPS 與加權平均股數。
- 毛利率、營業利益率、淨利率、ROE、ROA、負債比、流動比率與自由現金流。
- 計算值、估算值、公式、期間與來源標記。

EPS 優先採官方或 Yahoo 已揭露值；缺少已揭露 EPS 時，只有取得加權平均流通股數才計算。若只能用期末流通股數估算，前台會標示「估算值」。

## 資料採用原則

- 官方 TWSE／TPEx／MOPS、投信或公司正式資料優先。
- Yahoo、MoneyDJ、HiStock 只補官方缺漏並保留來源。
- 來源一致時標示多來源一致。
- 計算值與估算值不冒充官方數字。
- 來源衝突時不自動覆蓋。
- 整個區塊沒有可信資料時直接隱藏。

## 部署

將解壓後 `market-event-radar` 資料夾內的完整內容提交到 `main`。GitHub Actions 會逐批累積 Yahoo 與 ETF 詳細資料；單一來源失敗時保留該來源上一版成功資料。

## 限制

- MoneyDJ、HiStock、Yahoo 與投信網站可能調整 HTML 或阻擋自動請求，實際結果需以上傳後的 GitHub Actions 為準。
- ETF 每日完整持股、正式淨值與受益人資料仍以投信和交易所公告為準。
- 券商分點不等於最終客戶持倉，網站不會把分點成交誤標為真實持倉。
- 個人投資組合保存在使用者瀏覽器的 localStorage，不會上傳到伺服器。
