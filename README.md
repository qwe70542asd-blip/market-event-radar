# 市場事件雷達｜v11.2.7 台灣重大資訊與新聞來源修正版

本版只處理新聞與重大資訊，股票基本資料、財報、股利與籌碼資料留到下一階段逐項修正。

## 修正的主要故障

舊版使用不存在的 `feedparser.loads`，造成 Yahoo 股市、券商搜尋及多個 RSS 來源共同失敗。

v11.2.7 改為：

- 使用正式支援的 `feedparser.parse`。
- `feedparser` 不可用或來源 XML 異常時，使用 Python 內建 XML 備援解析。
- 單一來源失敗不會清空新聞檔。
- 保存每個來源最後成功時間與上次成功文章。

## 來源登錄

`data/news-sources.json` 目前登錄 99 個來源，分為：

- 上市櫃重大訊息
- 官方機關
- 財經與一般媒體
- 科技媒體
- Yahoo 與入口網站
- 券商與投顧
- 投信
- 廣域新聞搜尋

重要來源包含：

- 公開資訊觀測站上市、上櫃重大訊息
- 臺灣證券交易所、櫃買中心、金管會、中央銀行
- 經濟部、國發會、主計總處、財政部
- 中央社、經濟日報、工商時報、自由財經
- Yahoo 股市、鉅亨網、MoneyDJ
- 科技新報、財經新報、DIGITIMES、iThome、數位時代
- 主要券商與投信

廣域搜尋還會自動發現登錄表之外的台灣媒體，並將它們列入「額外發現媒體」。

## 更新方式

每 5 分鐘執行一次：

- 上市櫃重大訊息：每次必查。
- 官方與高優先來源：每次必查。
- 其他媒體、券商及投信：分成四組輪替，約 20 分鐘完成一輪。
- 所有請求並行執行，避免單一來源拖慢整體。
- GitHub Workflow 仍限制 14 分鐘；程式會記錄實際耗時。

## 新聞頁

新聞頁現在顯示：

- 新聞與公告總數
- 重大資訊數
- 活躍媒體數
- 設定來源數
- 每個來源的狀態、抓取方式、最後檢查及最後成功時間
- 官方、媒體、科技、券商、投信等來源篩選
- 重大訊息、財報、股利、ETF、政策、產業等主題篩選
- 重大優先或最新優先排序
- 公司股票代碼標籤
- 同事件其他來源數量

來源健康狀態使用 `payload.sources`，不再只顯示目前新聞中剛好有文章的三個媒體。

## 資料保存原則

- 保留最近 20 天。
- 相同標題去重。
- 同事件合併並保留相關來源連結。
- 只保存標題、摘要、時間、來源與原始連結，不複製新聞全文。
- 抓取失敗時保留上次成功新聞。

## 上傳

1. 解壓縮 ZIP。
2. 全部覆蓋 GitHub Desktop 倉庫根目錄。
3. Commit：

```text
修正台灣新聞與重大資訊來源 v11.2.7
```

4. Push origin。
5. 等待 `Update v11.2.7 Taiwan news and material information` 完成。
6. 等待 Pages 部署完成。
7. 網站按 `Ctrl + F5`。
8. 進入新聞頁確認「設定來源」約為 99；第一次完整輪替約需 20 分鐘。
