# 市場事件雷達｜v11.2.6 可讀性與完整個股資料版

本版集中修正三個核心問題：個股走勢／五檔／技術資料沒有實際內容、台股排行出現 NT$0 與 -100% 錯誤資料，以及筆電畫面字體過小。

## 個股查詢

在 `institutional.html` 輸入任何上市、上櫃股票或 ETF 代碼／名稱，結果直接在原頁面下方展開，共 13 個頁籤：

- 總覽
- 走勢
- 技術
- 五檔
- 分價
- 法人
- 融資券
- 當沖
- 基本
- 財報
- 股利
- 新聞
- 公告

同一套資料流程套用所有台股與 ETF；新上市、資料期數不足的標的會顯示目前能計算的指標，其餘欄位標示所需日線筆數，不再整區空白。

## 走勢與技術指標

走勢頁採三層備援：

1. TradingView 互動圖表，包含均線、RSI 與 MACD。
2. TWSE／TPEx 官方歷史行情。
3. Yahoo 日線／分鐘線備援。

技術頁會自行計算並顯示：

- MA5、MA20、MA60
- RSI 14
- MACD、訊號線與柱狀值
- KD
- 布林上／中／下軌
- 近 20 日壓力與支撐
- 綜合偏多／中性／偏空判讀
- TradingView 技術分析面板

## 五檔

- 盤中直接讀取 TWSE MIS 最佳五檔。
- 目前查詢標的每 5 秒更新。
- `live-tw-market` 會保存最後一次成功的買賣五檔，休市後不再因空陣列把資料洗掉。
- 每一檔使用同一套代碼與上市／上櫃市場判別。

## ETF 與官方基本資料

ETF 總覽不再硬塞股票的 EPS／本益比欄位，改顯示：

- 發行公司
- 基金經理人
- 類型與追蹤指數
- 投資策略
- 成立／上市日期
- 保管機構
- 淨值、折溢價、基金規模、內扣費用與配息頻率（官方有回傳時）

股票會按需查詢 TWSE／TPEx 官方估值與公司主檔，補本益比、股價淨值比、殖利率、發行股數、實收資本額及掛牌日期。

## 台股排行修正

排行現在只接受：

- 價格大於 0
- 昨收大於 0
- 漲跌幅介於 -50% 至 +50%

因此 NT$0、-100% 等來源錯值不會再進入漲跌排行。

## 筆電可讀性

以 Chromium、1366×768、100% 縮放進行可讀性檢查：

- 股票代碼／名稱：18px
- 價格：20px
- 漲跌幅：18px
- 日曆日期：21px
- 日曆星期與事件分類／數量：14px
- 技術指標標籤：14px
- 技術指標數值：21px

日曆桌面高度至少 760px，每格至少 124px，優先保留財報、經濟、股利等細節的閱讀空間。

## 官方與備援來源

- TWSE MIS：即時成交、漲跌停與最佳五檔。
- TWSE STOCK_DAY／TPEx 歷史行情：日線。
- TWSE BWIBBU_ALL／TPEx peratio：估值。
- TWSE／TPEx 公司及 ETF 主檔：公司、發行股數與基金資料。
- TWSE T86／TPEx 三大法人：法人買賣超。
- TWSE MI_MARGN／TPEx margin balance：融資融券。
- TWSE TWTB4U／TPEx intraday statistics：當沖。
- TradingView：互動走勢與技術分析。
- Yahoo Chart：分鐘線及歷史資料備援。

驗證包含：

- JavaScript、Python、Shell、JSON、YAML、HTML 引用
- 31 項單元測試
