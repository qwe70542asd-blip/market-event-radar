# 市場事件雷達 v11.4.0 最終整合版

這是一份可直接部署到 GitHub Pages 的完整專案，不是補丁包。

## 最終版整合內容

### 市場與排行

- 全球行情包含台灣、美國、日本、韓國、VIX、美國十年債、美元指數與台韓匯率。
- ETF 依 TWSE／TPEx 官方基金名單辨識，權證、ETN 與衍生商品不會混入 ETF 排行。
- 台股頁只顯示個股漲跌前 15 名與 ETF 漲跌前 15 名。
- 法人頁以搜尋為主，並提供熱門個股與熱門 ETF 前 10 名及綜合熱門分數。

### 日曆與事件

- 日期格只顯示重大事件、公司資訊件數與除權息家數。
- 日期視窗分成「重大事件／公司資訊／除權息」。
- 所有日期統一使用 Asia/Taipei，並進行語意去重。
- 事件卡片與事件詳情會依股票代碼、公司名稱及 CPI、JOLTS、FOMC、BOJ 等別名，自動附上事件前後三天內的相關新聞。

### 新聞與公告

- 新聞分成重大市場資訊、個股重要公告與一般財經新聞。
- 首頁、搜尋頁、分類頁、公告入口及無法還原的跳轉連結會自動排除。
- 個股公告標題優先整理為「代碼＋公司＋事件＋日期或數字」。
- 規則分析會輸出分類、影響程度、方向、影響市場、信心、重要度與市場判讀理由。
- 完整公告原文預設收起，先顯示摘要與結構化重點。

### 個股資料

每日資產工作會嘗試接入：

- TWSE／TPEx 公司主檔
- 本益比、股價淨值比、殖利率
- EPS 官方統計
- 一般業、金融業、金控業、證券期貨業、保險業與異業的損益表、資產負債表
- 最近十二期財務資料
- ROE、負債比、淨利率與流動比率計算

來源失敗時保留上一版成功資料。頁面會明確區分「尚未公告」「不適用」與「資料暫時無法取得」，不以 0 冒充缺值。

## AI 摘要說明

本版使用不需 API 金鑰的規則式語意分類、實體辨識、重點抽取與市場影響判讀，不會在公開網站中暴露模型金鑰。若未來在 GitHub Actions Secrets 串接模型 API，可直接覆寫 `ai_summary`、`why_it_matters` 等欄位，不需重做前端。

## 部署

1. 將整個 `market-event-radar` 資料夾內容提交到 GitHub 主分支。
2. 確認 GitHub Pages 來源為 `main` 根目錄。
3. 到 Actions 手動執行各更新工作一次。
4. 第一輪資料完成後重新整理網站；Service Worker 已更新為 v11.4.0。

## 限制

- 券商分點成交不等於券商、外資或最終客戶的真實持倉。
- 免費公開行情可能延遲。
- 官方網站改版時，解析器可能需要調整。
- 金融、保險與一般產業會計格式不同，無法合理計算的比率會顯示「不適用」。
