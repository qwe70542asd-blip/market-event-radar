# 市場事件雷達｜v11.2.5 個股整合情報版

本版整合三項需求：

1. 法人籌碼查詢結果直接在原頁面下方展開，不再跳轉個股頁。
2. 個股補上券商 App 常見的總覽、走勢、五檔、分價、法人、融資券、當沖、基本、財報、股利、新聞與公告。
3. 資料覆蓋頁可直接點股票查看八個欄位的解析狀態，0 / 8 不再被誤解成公司沒有公開資料。

## 個股查詢頁

在 `institutional.html` 輸入股票或 ETF 代碼／名稱後，下方會出現 12 個頁籤：

- 總覽
- 走勢
- 五檔
- 分價
- 法人
- 融資券
- 當沖
- 基本
- 財報
- 股利
- 新聞
- 公告

全程留在同一頁面，不需要切換到 `asset.html`。

## 即時與盤後來源

- 即時成交與最佳五檔：TWSE MIS，盤中每 5 秒更新目前查詢標的。
- 走勢與區間報酬：Yahoo Chart 分鐘線／日線備援。
- 分價：以分鐘 K 線成交量依價格聚合，明確標示為近似分價，不冒充券商逐筆分價。
- 法人：TWSE T86、TPEx 三大法人 OpenAPI。
- 融資融券：TWSE MI_MARGN、TPEx margin balance OpenAPI。
- 當沖：TWSE TWTB4U、TPEx intraday trading statistics。
- 財報／EPS／ROE／負債比：TWSE／TPEx OpenAPI 與 MOPS。
- 本益比／股價淨值比／殖利率：TWSE BWIBBU、TPEx peratio analysis。
- 新聞與公告：多來源新聞資料庫及公開資訊觀測站官方入口。

## 五檔與分價說明

五檔使用 MIS 回傳的最佳五檔買賣價格及委託量。

上市股票沒有提供免費、穩定且適合公開網站大量使用的完整逐筆成交分價 API，因此本版以分鐘成交量建立「近似分價」。畫面會清楚標示，不會把估算值冒充券商逐筆資料。

## 融資融券

融資融券沒有移除。更新程式會抓取：

- 融資前日餘額、買進、賣出、現金償還、今日餘額、限額與使用率。
- 融券前日餘額、賣出、買進、現券償還、今日餘額、限額與使用率。
- 資券互抵。
- 非信用交易標的顯示「非信用交易標的或官方未回傳」，不以 0 代替。

## 資料覆蓋

`coverage.html` 的股票代碼改成原頁面展開：

- 八個欄位目前值
- 缺少欄位
- 已保存財報季度
- 為何可能出現 0 / 8
- 公開資訊觀測站及官方估值查詢入口

0 / 8 表示更新程序目前沒有成功解析八個欄位，不代表公司沒有財報。

## 官方欄位相容性

更新程式擴充中英文欄位別名，包括：

- EPS、營業收入、營業利益、淨利
- 流動資產、總資產、流動負債、總負債、權益
- 本益比、股價淨值比、殖利率
- 發行股數、實收資本額與掛牌日期

用來降低不同產業財報格式造成的 0 / 8。
