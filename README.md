# 市場事件雷達 v11.4.7

本版以事件月曆為首頁主視覺，重做新聞入口網站式排版，並新增 Yahoo 詳細資料補充通道。官方 TWSE／TPEx／MOPS 數值仍為第一優先，Yahoo 僅補官方空白欄位並顯示參考來源。

本版以 v11.4.5 為基準，完成首頁重排、統一財經新聞、個人資產總覽、成交動能，以及股票／ETF 資料來源交叉驗證框架。

## 首頁

- 精選重大資訊移到首頁最上方。
- 重大資訊擴大納入台灣與全球龍頭、主要產業鏈、主管與專業經理人發言、財報財測、產品發表會及市場級事件。
- 新增「我的資產總覽」，讀取瀏覽器內的投資組合，顯示總資產、成本、累計與今日損益、報酬率及配置比例。
- 缺少行情的資產不會被當成零元，畫面會標示暫估範圍。
- 今日市場重點改為盤勢判讀、市場廣度、上市外資方向與成交動能。
- 成交動能比較當日成交金額與最近 20 個交易日平均。
- 移除過期櫃買指數卡、上櫃法人摘要及一般頁面的技術性來源狀態卡。

## 新聞

- 所有媒體新聞合併成單一「最新財經新聞」，依發布時間排序。
- 可依新聞類別與媒體來源篩選，不再讓每一家媒體各占一個大型區塊。
- 精選重大資訊採加權評分，考慮龍頭公司、產業重要度、主管發言、財報與資本支出、官方佐證、多來源報導及時效性。
- 媒體新聞、官方市場公告與個股重大訊息保持分流。
- TPEx／櫃買中心網頁型新聞與公告暫停使用；可驗證的上櫃結構化行情、估值、財務與公司資料仍保留。
- 只發布可閱讀的繁體中文內容；亂碼、入口頁、搜尋頁、政策頁及無具體事件內容會被排除。

## 資料可信度

- 官方資料維持最高優先級。
- 新增 Yahoo Finance 圖表行情作為漸進式次級參考，不會直接覆蓋官方數值。
- Goodinfo 與 Yahoo 台股頁面提供為人工核對連結，不自動擷取頁面數字。
- 每支股票／ETF 可標示：官方確認、多來源一致、參考資料、資料衝突或資料缺漏。
- 不同來源發生衝突時不會自動選擇其中一個數值。
- 完整來源健康、衝突與缺漏統計集中在 `data-status.html`。

## 新增資料通道

- `live-secondary-reference`：次級行情參考，分批處理全部股票與 ETF。
- `live-data-verification`：比較官方行情、月營收、股利及次級參考資料。
- `market-volume-history`：保存市場成交金額歷史，用於計算 20 日成交動能。

## 部署

將解壓後 `market-event-radar` 資料夾內的完整內容提交到 `main`。GitHub Actions 會建立並更新各自的 live 資料分支。

## 限制

- 外部資料來源的實際可用性必須以上傳後的 GitHub Actions 執行結果確認。
- 次級股票網站只作為參考或人工核對；與官方資料衝突時不會覆蓋官方數值。
- 個人資產總覽保存在使用者自己的瀏覽器 localStorage，不會同步到伺服器。
