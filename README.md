# 市場事件雷達 v11.4.2｜新聞恢復與歷史資料整合版

這是一份可直接部署到 GitHub Pages 的完整專案，不是補丁包。

## 既有詳情頁功能

股票與 ETF 分流、K 線、公司與基金資料均沿用上一版。

## v11.4.2 本版重點

### 股票與 ETF 正式分流

- 股票頁只顯示公司、估值、財務、月營收、法人籌碼、股利、事件與新聞。
- ETF 頁只顯示基金行情、淨值、折溢價、規模、受益人數、投信、經理人、保管銀行、成立日、上市日、策略、費用、配息與正式持股。
- ETF 不再顯示 EPS、ROE、負債比或「等待公司財報」。
- 一般股票不再顯示 ETF 成分股。
- ETF 沒有正式持股資料時，整個成分股區塊直接隱藏。

### 已知資料盡量完整呈現

股票資料來源包含：

- TWSE／TPEx 公司主檔
- 公司全名、統一編號、董事長、總經理、發言人、電話、地址、官方網站與主要業務
- 上市／上櫃日期、發行股數、實收資本額
- 本益比、股價淨值比、殖利率、EPS、ROE、負債比、淨利率及流動比率
- 最近十二期損益表與資產負債表
- 最近二十四個月營收
- 股利與除權息
- 法人、融資融券、當沖與相關事件新聞

ETF 資料來源包含：

- TWSE 基金基本資料彙總表及既有官方基金資料
- 正式名稱、發行投信、基金經理人、保管銀行
- 成立日、上市日、基金類型、主動／被動、追蹤指數或投資策略
- 經理費、保管費、配息頻率、風險等級、槓桿／反向倍數
- 淨值、折溢價、基金規模、受益人數及受益權單位數（來源有提供時）
- 正式持股、產業配置與配息紀錄（來源有提供時）

### K 線取代券商分點

- 個股與 ETF 詳情頁改為 K 線及成交量。
- 提供 1 個月、3 個月、6 個月、1 年切換。
- 顯示 MA5、MA20、MA60、區間高低點及區間漲跌幅。
- 優先讀取 TWSE／TPEx 公開歷史行情，必要時使用 Yahoo 行情作備援。
- 歷史行情無法取得時，只顯示清楚的狀態訊息，不影響其他資料區塊。

### 顯示規則

- 有有效資料才顯示欄位。
- 整個區塊沒有有效內容時直接隱藏。
- 缺值不以 `0` 補填。
- 產業代碼轉為中文產業名稱。
- `19931022`、民國日期等格式統一轉為可讀日期。
- 每個資料區塊顯示來源或更新時間。

## 既有功能

市場排行、法人搜尋、全球行情、日曆三分類、事件日期追蹤、新聞與公告分類、事件相關新聞、投資組合與資料覆蓋頁面均保留。

## 部署

1. 將整個 `market-event-radar` 資料夾內容提交到 GitHub 主分支。
2. 確認 GitHub Pages 來源為 `main` 根目錄。
3. 到 Actions 手動執行 `Update v11.4.2 assets and audit`。
4. 資產工作每日上午及晚間各更新一次；完成後重新整理網站。
5. Service Worker 已更新為 v11.4.2，舊版快取會自動清除。

## 限制

- 各投信的主動式 ETF 持股揭露方式不一致；沒有正式資料時不顯示成分股。
- 公開歷史行情端點若限制跨網域連線，K 線會改用備援來源或顯示暫時無法取得。
- 免費公開行情可能延遲。
- 官方網站改版時，解析欄位可能需要同步調整。
- 新聞 0 則的資料流問題不包含在本次 v11.4.2 詳情頁整合範圍。


## v11.4.2 新聞與歷史資料修復

- 新聞工作流程會先恢復 `live-news` 最後成功資料，空結果不再發布。
- Google News 無法解析原站網址時，保留該篇文章的專屬頁面，不會把整批新聞刪除。
- 月營收每週從 MOPS 歷史月報回補最近 60 個月，日常更新再合併最新月份。
- 股利採官方當期資料加 MOPS 歷史分批回補，進度寫入 `data/asset-history-state.json` 並跨排程保存。
- 股利現金與股票金額只使用明確的每股欄位，避免把總金額、期別或其他數字誤判成每股股利。
