# 市場事件雷達 v11.4.12

本版直接以 v11.4.11 完整專案為基礎整合，不是單一 HTML 重製版。原本的資料更新腳本、GitHub Actions、新聞通道、台股排行、法人籌碼、ETF 資料覆蓋、個股頁面與投資組合功能全部保留。

## v11.4.12 雙模式事件月曆

首頁月曆拆成兩個可切換模式：

- **市場事件日曆**：總經、央行、重大事件、財報與公司資訊。
- **股利股息日曆**：除權、除息、股利方案與股利發放日期。

切換模式時，搜尋提示、篩選選項、日期格內容、月份統計與單日明細會同步切換。使用者最後選擇的模式會保存在瀏覽器中。

## 今日新公布日期

- 只顯示今日由官方事件監測器新確認或改期的日期，不再混入一般新聞。
- 改期事件同時顯示新日期與原日期。
- 每筆資料可直接跳到對應月份，並自動切換到市場事件或股利股息模式。
- 目標日期會在月曆中短暫醒目標示。

## 首頁版型

- 「我的資產總覽」與「即時大盤資訊」改為左右各半。
- 即時大盤區保留盤勢判讀、市場廣度、外資方向、成交動能與全球行情。
- 雙模式月曆改為整頁寬度，避免右側行情欄壓縮日期內容。

## 原有功能完整保留

- 台股個股與 ETF 排行及搜尋。
- 法人、當沖、融資與融券資料。
- ETF 基本資料、持股、產業配置與股利紀錄。
- 多來源財經新聞與亞洲總體風險通道。
- 個人投資組合 localStorage、JSON 匯入與匯出。
- GitHub Actions 自動更新與各 live-data branch。
- 官方來源失敗時保留最後成功資料，不發布空白資料。

## 部署

1. 解壓縮 ZIP。
2. 開啟 `market-event-radar` 資料夾。
3. 將資料夾內全部內容複製到 GitHub Desktop 顯示的 repository 根目錄。
4. 在 GitHub Desktop 提交 `Update to v11.4.12`。
5. Push origin。

請勿只複製 `index.html`；本版必須連同 `assets`、`data`、`scripts`、`.github` 等完整目錄一起部署。

## 限制

- 首次部署後，事件資料必須由 `Update v11.4.12 events` 工作流程建立監測基準，之後新確認或改期才會被標示為「今日新公布日期」。
- 第三方網站可能調整 HTML 或限制自動請求；系統會保留上一份成功資料。
- 個人投資組合只保存在使用者瀏覽器，不會上傳到 GitHub。
- 所有內容僅供市場觀察，不構成投資建議。
