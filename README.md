# 市場事件雷達｜v11.2.1 高頻行情版

本版延續六個獨立資料分支，另外加入台股／ETF 五秒快照、虛擬貨幣每秒 WebSocket 與新聞每五分鐘刷新。

## 更新頻率

| 資料 | 畫面更新 | GitHub 分支備援 |
|---|---:|---:|
| 台灣加權、櫃買指數 | 盤中每 5 秒 | 全球市場分支每 10 分鐘 |
| 首頁投資組合台股／ETF | 盤中每 5 秒 | 台股分支每 5 分鐘 |
| 單一台股／ETF 詳情 | 盤中每 5 秒 | 台股分支每 5 分鐘 |
| 台股排行目前前 20 漲／跌與持股 | 盤中每 5 秒 | 全市場基準每 5 分鐘 |
| 虛擬貨幣 BTC／ETH／BNB／SOL／XRP | 每 1 秒推送 | 斷線時 CoinGecko 每 30 秒 |
| 多來源財經新聞 | 每 5 分鐘檢查 | `live-news` 每 5 分鐘產生 |

台股畫面只有在台灣時間平日 08:30–13:35 使用五秒快照；其他時間降為每 60 秒檢查，避免休市期間無意義地連線。

## 為什麼不是全部台股每五秒重新排序

全市場約有數千檔股票與 ETF。每位網站訪客每五秒抓完整市場，會產生大量連線並增加被來源限制的風險。因此本版採用兩層架構：

1. 目前畫面、投資組合與單一標的：五秒快照。
2. 全市場排行基準：GitHub Actions 每五分鐘更新。

台股排行頁會持續更新目前前 20 名上漲、前 20 名下跌與使用者持股；完整市場排序則以五分鐘分支資料校正。

## 虛擬貨幣

- 使用 Binance market-data WebSocket。
- `miniTicker` 約每秒推送價格、24 小時漲跌、高低與成交量。
- WebSocket 斷線會自動重新連線。
- 連線中斷期間改用 CoinGecko 30 秒備援。
- 投資組合內的虛擬貨幣與虛擬貨幣詳情頁也共用秒級串流。

## 新聞

`Update v11.2.1 multi-source news` 改為每五分鐘排程：

```text
03、08、13、18、23、28、33、38、43、48、53、58 分
```

首頁與新聞頁也會每五分鐘檢查 `live-news`；切回瀏覽器分頁時會立即再檢查一次。

任何一區失敗、延遲或重跑，都不會卡住其他區塊。

## 上傳

1. 解壓縮 `market-event-radar-v11.2.1-complete.zip`。
2. 將資料夾內全部內容覆蓋到 GitHub Desktop 倉庫根目錄。
3. Commit：
   ```text
   高頻行情與新聞更新 v11.2.1
   ```
4. Push origin。
5. 等六個 GitHub Actions 完成。
6. 等 Pages 部署完成後按 `Ctrl + F5`。
7. 開啟 `data-status.html` 檢查各分支與虛擬貨幣直連狀態。

## 注意

GitHub Actions 排程本身最短只能每五分鐘執行，因此「五秒台股」和「每秒虛擬貨幣」是在使用者瀏覽器開啟網站時直接更新，不是靠 Actions 每秒建立檔案。
