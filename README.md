# 市場事件雷達 v11.4.17

本版修正六大指數 K 線讀到舊快取、成交均量必須等待逐日累積，以及日曆與新聞只能保留近期資料的問題。

## v11.4.17 本次重點

### 六大指數 K 線穩定化

首頁保留台灣加權、韓國 KOSPI、日經 225、NASDAQ、費城半導體及 S&P 500。

- GitHub Actions 更新前先還原 `live-global-market` 上一次成功資料。
- 瀏覽器優先透過 GitHub Contents API 讀取最新資料，避免 Raw 分支 CDN 回傳舊 JSON。
- 線上檔缺 K 線時，使用瀏覽器上一次成功的 `candles[]`，不再整張顯示「等待歷史 K 線」。
- 台灣加權使用 TWSE 官方日 OHLC 優先；海外指數使用 Yahoo 日 OHLC。

### 成交均量直接從網路回補

- 每次排程直接查詢 TWSE／TPEx 官方歷史成交量值。
- 回補範圍固定為 `2026-01-01` 至執行當日。
- 直接計算 5 日、20 日及 60 日平均成交金額。
- 本地 `market-volume-history.json` 僅作最後成功快取，不再等待網站累積 20 個交易日。

### 2026 年日曆回補

- 行事曆保留 `2026-01-01` 起的已查證事件及官方未來日期。
- BLS、BEA、FOMC、台灣除權息、股利方案、股東會及可確認日期的公司事件重新從網路來源整理。
- 新增 Federal Reserve FOMC 官方會議日曆來源。
- 舊月份不會在下一次更新時因「最近 14／30 天」條件被刪除。

### 新聞歷史與自動清理

- 新聞排列固定為發布時間由新到舊。
- 2026 年 1 月 1 日以前的新聞自動刪除。
- 最近 30 天完整保留；31–90 天提高重要度門檻；更早資料只保留重大政策、央行、財報、產業或系統性事件。
- 第一次推送 v11.4.17 時，各新聞工作流程會以 Google News 歷史搜尋補抓缺少月份；之後一般排程只更新近期新聞，避免重複大量查詢。
- 新聞原圖失效時仍使用相關主題備援圖。

### 全市場股票資料延續

- 全部 TWSE 上市與 TPEx 上櫃股票基本資料。
- 股票基本資料與進階財務資料分開計算完整度。
- 官方來源優先，Yahoo、MoneyDJ、HiStock 等只補充可驗證欄位。

## 部署

1. 解壓縮 ZIP。
2. 將 ZIP 內所有檔案與資料夾複製到 GitHub Desktop repository 根目錄。
3. 覆蓋同名檔案，但保留原本的 `.git` 資料夾。
4. Commit 訊息填 `Update to v11.4.17`。
5. Push origin。

推送後，全球行情、台股成交量值、事件日曆及各新聞來源工作流程會自動執行。第一次新聞歷史補抓可能比平常更新稍久。

## 資料原則

- 歷史行情與行事曆優先直接查詢網路官方來源。
- 本地資料只作快取與來源暫時失敗時的備援。
- 不自行猜測事件日期或編造新聞。
- 所有內容僅供市場觀察，不構成投資建議。
