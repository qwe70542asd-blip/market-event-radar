# 市場事件雷達｜v11.2.4 法人與融資查詢版

本版將法人籌碼頁改成查詢式介面，並補上個股法人、融資與融券明細。

## 法人籌碼頁

- 最上方新增「回到首頁」。
- 可選擇上市／上櫃。
- 可選擇已保存的交易日期。
- 按「查詢市場資料」後顯示：
  - 外資買賣超
  - 投信買賣超
  - 自營商買賣超
  - 三大法人合計
  - 融資餘額與增減
  - 融券餘額與增減
- 新增個股代碼／名稱搜尋。
- 搜尋後在頁面下方顯示：
  - 參考股價與漲跌
  - 個股外資、投信、自營商與合計
  - 融資前日餘額、買進、賣出、現金償還、今日餘額、使用率
  - 融券前日餘額、賣出、買進、現券償還、今日餘額、使用率
  - 資券互抵與官方備註
- 非信用交易標的不會顯示假 0，會標示「非信用交易標的或官方未回傳」。
