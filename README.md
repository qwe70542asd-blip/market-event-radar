# 市場事件雷達 v11.4.3｜多來源與歷史資料分流版

這是一份可直接部署到 GitHub Pages 的完整專案，不是補丁包。

## 獨立資料通道

媒體、官方公告與歷史資料不再共用同一個更新工作：

- 中央社：產經證券與科技 RSS
- MoneyDJ：新聞頁
- 鉅亨網：台股與美股新聞
- 經濟日報：即時新聞
- 自由財經：財經新聞
- 官方市場公告：證交所新聞與櫃買中心新聞稿
- 個股重大訊息：上市、上櫃公司結構化重大訊息
- 月營收歷史：最新月營收與五年歷史小批次回補
- 股利歷史：官方股利彙總與公司歷史小批次回補

每個通道都有自己的 JSON、Seed、GitHub Actions、資料分支、狀態與最後成功資料。單一來源失敗時，只影響該來源。

## 新聞頁

新聞頁依序顯示來源健康狀態、重大市場資訊、官方市場公告、個股重大訊息、五家媒體獨立區塊，以及可依來源、分類與關鍵字搜尋的全部媒體新聞。

首頁、事件頁與股票／ETF 詳情頁會合併讀取成功的新聞通道，但不改寫各來源原始資料。

## 月營收與股利

月營收不再由資產主檔一次抓取 120 個歷史頁面。獨立工作每次只處理四個月份、最多兩條連線，成功月份立即合併保存。

股利歷史每次處理少量公司。主游標不會因個別公司失敗而停住；失敗標的會加入獨立重試佇列。

股票／ETF 詳情頁優先讀取這兩條獨立通道，尚未累積資料時才使用資產主檔中的最新備援資料。

## 部署

1. 將完整 `market-event-radar` 資料夾提交到 GitHub `main`。
2. GitHub Pages 使用 `main` 根目錄。
3. 推送後各通道會依自己的檔案變更自動執行。
4. 在 `data-status.html` 查看每條通道的筆數、狀態與更新時間。
5. Service Worker 已更新為 v11.4.3，舊快取會自動清除。

## 限制

- 媒體網站改版或限制自動存取時，只會影響該媒體解析器。
- 網站只保存標題、公開摘要、時間與原文連結，不複製全文。
- MOPS 歷史資料採小批次累積，第一次部署不會立刻完成全市場五年資料。
- 各投信 ETF 揭露格式不一，沒有正式持股資料時不顯示成分股。
- 免費行情與官方排程可能延遲。
