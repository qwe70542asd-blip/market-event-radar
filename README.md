# 市場事件雷達 v11.3.0

本版依照「延續市場事件雷達」與「市場事件雷達網頁」兩邊討論完成整合。

## 本次介面調整

- 首頁移除虛擬貨幣排行，改為今日市場重點。
- 日曆日期格只顯示重大事件、公司資訊總數與除權息家數。
- 點開日期後分成重大事件、公司資訊、除權息三頁。
- 修正以 UTC 切日期造成事件顯示錯一天的問題。
- 相同除權息與事件資料會去除重複。
- 事件更新沒有新日期時，改顯示最新重大資訊或近期高影響事件。
- 新聞只保留可辨識的文章或官方公告，移除首頁與無效連結。
- 清除新聞標題與摘要中的 HTML 原碼。
- 新聞加入免金鑰規則式分類：分類、影響程度、偏多偏空、可能影響市場及文章大綱。
- 台股頁固定顯示個股漲幅、個股跌幅、ETF 漲幅、ETF 跌幅前 15 名。
- 其他股票與 ETF 只有在使用者輸入搜尋時才顯示。
- 法人頁只有搜尋後才顯示標的籌碼，並新增熱門個股與熱門 ETF 前 10 名。
- 所有缺值顯示「—」，不以 0 冒充有效資料。

## 自動更新

- 市場事件：每 10 分鐘。
- 財經新聞：每 10 分鐘。
- 台股與法人資料：依 GitHub Actions 排程更新。
- 單一來源失敗時保留上一版成功資料。

## AI 摘要說明

目前使用不需 API 金鑰的規則式分類與抽取摘要，避免在公開 GitHub Pages 暴露金鑰。日後可在 GitHub Actions Secrets 中加入模型 API，輸出相同欄位即可直接替換。

## 資料限制

- 券商分點成交不等於券商或外資的真實持倉。
- 免費公開行情可能延遲。
- 官方網站改版時，對應解析器可能需要調整。
- 主動式 ETF 或部分投信的成分股可能延遲揭露。
