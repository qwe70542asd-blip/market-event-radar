# 市場事件雷達｜v11.2.2 首次分支建立修正版

本版修正上一版第一次拆分資料分支時出現的兩個失敗：

1. `Taiwan chips` 在盤中執行時只查當天資料，但官方盤後資料尚未公布，因此流程失敗。
2. `event calendar` 的新 `live-events` 分支尚未建立，而主分支事件種子為空，驗證因此失敗。

## 修正內容

### 法人／融資券

- 不再只查今天。
- 會從今天開始，向前尋找最近 14 個平日。
- 找到最近有官方資料的日期後才發布。
- 官方網站暫時無回應時，保留上一筆資料並標記 `warning`，不再讓整個 Workflow 失敗。
- 推送新版時即使在盤中執行，也能取得上一個已公布交易日的資料。

### 市場事件月曆

- 新 `live-events` 分支若尚未建立或內容為空，會自動從舊 `live-data` 搬移最後一份已驗證事件資料。
- 搬移後再套用 35 天保留與 370 天未來事件範圍。
- 舊版事件資料不需要人工複製。
- 之前 22 分鐘超時的是舊 Workflow 紀錄，不影響新版。

### 投資組合

- 除了已知舊版 localStorage 名稱，現在也會搜尋同網域內名稱包含 `market` 與 `portfolio` 的舊資料。
- 避免升級後持股暫時顯示為 0。
- 瀏覽器真的已清除網站資料時，仍無法從 GitHub 恢復，因為投資組合原本只存在使用者瀏覽器。

### 行情與新聞頻率

- 台股／ETF 目前畫面：盤中每 5 秒。
- 完整市場基準：每 5 分鐘。
- 虛擬貨幣：WebSocket 約每秒推送。
- WebSocket 7 秒未連線會自動切換 CoinGecko 30 秒備援。
- 新聞：每 5 分鐘更新。

## 目前畫面為何是空的

上一版上傳後，GitHub Pages 先完成部署，但 `live-assets` 仍在建立，`live-events` 與 `live-tw-chips` 又第一次失敗。因此頁面會暫時看到：

- 加權與櫃買等待行情
- 投資組合顯示 0
- 月曆空白
- 法人資料沒有內容

這不是版面程式全部壞掉，而是新資料分支尚未全部建立。

## 上傳

1. 解壓縮 `market-event-radar-v11.2.2-complete.zip`。
2. 將資料夾內全部檔案覆蓋到 GitHub Desktop 倉庫根目錄。
3. Commit：
   ```text
   修正首次資料分支建立 v11.2.2
   ```
4. Push origin。
5. 等下列流程：
   - Update v11.2.2 assets and financials
   - Update v11.2.2 event calendar
   - Update v11.2.2 Taiwan chips
   - 其他已成功流程可讓自動排程處理
6. 等 Pages 部署完成後按 `Ctrl + F5`。
7. 開啟 `data-status.html` 檢查各區塊。

## 不需要做的事

- 不需要刪除成功的新聞、台股行情與全球行情分支。
- 不需要刪除舊 Actions 紀錄。
- 不要在 assets 流程尚未完成時重複按 Run workflow。
