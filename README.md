## 部署

1. 解壓縮 ZIP。
2. 將 ZIP 內全部檔案複製到 repository 根目錄並覆蓋。
3. 保留原本的 `.git` 資料夾。
4. Commit 訊息填 `Update to v11.4.19`。
5. Push origin。

資料僅供市場觀察，不構成投資建議。
