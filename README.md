### K 線資料架構

- 台灣加權：TWSE 官方每日 OHLC 優先，Yahoo Chart 作為報價及備援。
- 韓國、日本、美國指數：Yahoo Chart 近三個月日 OHLC。
- 每個指數保存最多 70 筆，首頁顯示最近 60 個交易日。
- 一個來源失敗時只切換該指數的上一次成功快取，不會讓六張圖全部消失。
- 卡片顯示開、高、低、最新指數、漲跌、資料來源、更新時間及即時／快取狀態。

## 部署

1. 解壓縮 ZIP。
2. 將 ZIP 內全部檔案與資料夾複製到 GitHub Desktop 顯示的 repository 根目錄。
3. 覆蓋同名檔案，但不要刪除 `.git` 資料夾。
4. Commit 訊息填 `Update to v11.4.16`。
5. Push origin。
6. 推送後 GitHub Actions 會自動執行 global market 更新；也可手動執行 `Update v11.4.16 global market`。

首次更新完成後，`live-global-market` 分支的 `market-snapshot.json` 會包含六個指數的 `candles[]` 日 K 陣列。

## 資料原則

- 官方資料優先。
- 第三方資料只作補充與備援。
- 抓取失敗時保留最後成功資料，不用空值覆蓋。
- 所有內容僅供市場觀察，不構成投資建議。
