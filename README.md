# 市場事件雷達 v11.4.8

本版延續事件月曆主軸，將首頁上方控制區縮成低高度摘要列，並完成不使用 AI 的新聞圖片流程。Yahoo 個股／ETF 補充通道、官方優先驗證與多來源新聞分流均完整保留。

## 首頁

- 快捷入口列移到首頁最上方並縮小。
- 我的資產總覽與今日市場重點緊接在快捷列下方。
- 資產六項摘要改成桌機單排，市場四項摘要改成緊湊排列。
- 未設定投資組合時不再保留大片空白。
- 事件月曆維持首頁主要大型內容，全球市場行情位於右側窄欄。
- 手機版依序顯示快捷列、摘要、事件月曆與全球行情。

## 新聞圖片

不使用 AI 生成新聞圖片，也不需要任何圖片 API 額度。

圖片取得順序：

1. RSS enclosure、media content 或 media thumbnail。
2. 新聞列表頁提供的圖片。
3. 文章頁 `og:image`。
4. Twitter image。
5. JSON-LD 圖片。
6. 文章內第一張有效大圖。
7. 本地分類 SVG 預設圖。

本地預設圖包含市場、總經、利率、科技、財報、個股、原物料、全球、政策與地緣政治。外部圖片失效時，前端會自動切換到對應分類圖。

## 新聞與資料

- 媒體新聞、官方市場公告與個股重大訊息維持分流。
- 新聞卡片整張可直接開啟原文。
- 前台只顯示內容分類，不顯示媒體來源篩選列。
- Yahoo 詳細資料通道持續分批補充公司資料、財務、股利、籌碼與 ETF 資訊。
- 官方 TWSE／TPEx／MOPS 資料仍為第一優先；Yahoo 只補官方空白欄位。
- 不同來源衝突時不自動覆蓋。

## 部署

將解壓後 `market-event-radar` 資料夾內的完整內容提交到 `main`。GitHub Actions 會更新行情、事件、各媒體新聞、Yahoo 詳細資料與其他獨立資料分支。

## 限制

- 部分媒體會阻擋外部圖片連結；遇到此情況會使用本地分類圖。
- 每個媒體來源每次只補抓有限數量的缺圖文章，避免工作流程過久或對網站造成過量請求。
- 外部來源實際回應仍須以上傳後的 GitHub Actions 結果為準。
- 個人投資組合保存在使用者自己的瀏覽器 localStorage，不會上傳到伺服器。
