# 市場事件雷達｜v11.1.4 完整整合版

## v11.1.4 修正

- 修正 GitHub Actions 的 MOPS 財報解析錯誤：補上 `html5lib` 依賴。
- MOPS HTML 解析改為先使用 `lxml`，失敗時自動改用 `html5lib`。
- `daily data` 在抓資料前會先檢查 pandas、lxml、html5lib，依賴缺少時會直接顯示明確錯誤。
- 保留 1595 EPS 回歸驗證；解析器正常後仍會阻止不完整資料發布。

- 台灣加權、櫃買指數與首頁／個股／投資組合行情，瀏覽器每 60 秒主動向 TWSE MIS 重新抓取；失敗時退回 GitHub `live-data` 備援。
- GitHub Actions 仍以每 5 分鐘更新完整台股行情，因 GitHub 排程無法保證每分鐘執行。
- 股票財務改成「全市場自動稽核」：上市與上櫃主檔全部逐檔檢查，不再靠人工點開發現缺漏。
- 新增 MOPS 最近四季歷史回補；當最新一季尚未申報時，自動使用上一個已公布季度，不再顯示錯誤的 `0/8`。
- 整合官方 EPS、營益分析、損益表、資產負債表、本益比、股價淨值比、殖利率、月營收與股利。
- 新增 `coverage.html`，可查看全市場總檔數、欄位覆蓋率及缺漏股票清單。
- 每次更新會特別驗證上櫃 `1595` 是否成功取得官方 EPS；驗證失敗則不發布不完整資料。

- 五個主要功能入口移至首頁最上方，放大文字並壓縮卡片空白。
- 新增「台灣加權指數／台灣櫃買指數」雙卡橫向區塊，顯示指數、漲跌點、漲跌幅、日高低與行情時間。
- 首頁投資組合最多顯示 7 個標的，依目前市值由大到小排序；其餘標的以 `…` 卡片連到完整組合。
- 全球市場區不再重複顯示台灣加權與櫃買指數。
- 月曆與右側行情改成自然高度：虛擬貨幣卡片只到最後一個幣種，月曆再依右側總高度平均分配每週列高。
- 新聞加入事件群組、排名模板收斂與不同來源交錯排列，避免同一家媒體連續鋪滿畫面。
- 上市／上櫃公司重大訊息納入新聞資料，個股頁可依代碼與公司名稱自動關聯官方公告。
- ETF 基本資料排程新增基金經理人、發行／經理公司、基金類型、標的指數、成立日期、上市日期與保管機構。
- ETF 頁面不再使用示意持股或示意產業配置；未取得官方資料時明確顯示排程狀態。
- `00663L` 已加入官方備援資料：國泰臺灣加權正2、經理人蘇鼎宇、標的指數臺灣日報酬兩倍指數。

這個資料夾可直接覆蓋 GitHub Pages 倉庫根目錄。網站不需要另外架設資料庫：靜態備援資料放在 `data/`，GitHub Actions 會把最新動態資料發布到既有的 `live-data` 分支，前端再自動選擇最新且內容最完整的來源。

## 上傳方式

1. 解壓縮本檔案。
2. 進入 `market-event-radar-v11.1.4-complete` 資料夾。
3. 將資料夾「裡面的全部檔案與資料夾」上傳到 GitHub 倉庫根目錄。
4. 選擇覆蓋同名檔案並提交。
5. 不要刪除既有 `live-data` 分支；網站會沿用上次成功的事件、新聞與市場資料。
6. 到 **Actions** 手動執行一次：
   - `Update v11.1.4 daily data`
   - `Update v11.1.4 Taiwan market`
   - `Update v11.1.4 multi-source news`
7. GitHub Pages 發布完成後，使用 `Ctrl + F5` 重新整理一次。

## 資料更新架構

- `.github/workflows/update-news.yml`
  - 每 10 分鐘更新多來源財經新聞。
- `.github/workflows/update-tw-market.yml`
  - 台灣交易時段每 5 分鐘更新台股／ETF 行情。
  - 盤後嘗試更新三大法人、融資與融券。
- `.github/workflows/update-daily.yml`
  - 更新正式證券主檔、事件封存與全球市場行情。
- `live-data`
  - 只存動態 JSON 與 seed 檔。
  - 前端會優先讀取此分支；失敗時退回主分支或安裝包備援。

## 重要資料原則

- 代碼輸入若像正式證券代碼，必須完全相符，避免錯字被模糊配對。
- `009816` 是正式 ETF 代碼，不可誤判為 `00981A`。
- ETF 不顯示個股 EPS／本益比；個股不顯示 ETF 內扣費用。
- 沒有可驗證數值時保留 `null`，前端顯示資料狀態。
- 券商分點沒有授權資料時只提供官方查詢入口，不建立猜測排行。
