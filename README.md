# 市場事件雷達 v11.4.20

本版將資料策略改為「寧可暫不顯示，也不發布已知不一致的數字」。公開資料在寫入即時分支前，必須通過市場算術、OHLC、事件日期、新聞股票關聯與完整度定義檢查。

## 本次修正

- 海外指數單日漲跌改由相鄰兩個交易日計算，不再使用可能代表圖表區間起點的 `chartPreviousClose`。
- 市場價格、漲跌點與漲跌幅必須算術一致；K 線必須符合高低價順序，否則停止發布並保留上次成功資料。
- 台灣重大訊息依欄位標籤選取財報通過日、法說會日、除權息日、股利發放日或公司行動日。
- 財報期間的起訖日期不再被誤當成日曆事件日期；無法確認的日期不發布。
- BLS 新增官方年度 HTML 行事曆備援；BEA 同時解析主要及完整官方排程頁。
- 新聞內的數字只有存在於完整上市櫃主檔時才可判定為股票代碼。
- 公司名稱採最長名稱優先，避免「南亞科」同時錯誤匹配成「南亞」。
- 「公司主檔完整度」與「財務資料完整度」分開顯示，不再把公司地址、董事長等資料完整誤稱為財報完整。
- 產業代碼轉換為一般使用者可讀的產業名稱。
- 新增 `scripts/validate_public_data.py`，驗證失敗時 GitHub Actions 不會把錯誤資料發布到即時分支。

## 更新頻率

- 台股與全球市場：約每 5 分鐘更新。
- 重大事件日曆：約每 10 分鐘檢查官方來源。
- 新聞依來源約每 10～15 分鐘更新。
- 外部來源失敗或資料驗證失敗時，保留上一次通過驗證的資料；沒有可信資料時顯示待確認，不以錯誤值補位。

## 部署

1. 解壓縮 ZIP。
2. 將 ZIP 內全部檔案複製到 repository 根目錄並覆蓋。
3. 保留原本的 `.git` 資料夾。
4. Commit 訊息填 `Update to v11.4.20`。
5. Push origin，等待 GitHub Actions 完成第一輪資料驗證與更新。

資料僅供市場觀察，不構成投資建議。
