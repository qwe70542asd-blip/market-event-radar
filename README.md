# 市場事件雷達 v11.3.0

這是完整專案，不是補丁包。解壓後可直接覆蓋原本的 `market-event-radar` 專案內容。

## 本版整合

- 市場事件月曆與「今日新公布日期」監控。
- 台股上市、上櫃排行與個股頁。
- 法人、當沖、融資、融券與券商分點觀察。
- 新聞、多市場行情、虛擬貨幣滾動排行。
- ETF 基本資料與可取得的成分股日期／來源。
- 個人投資組合使用瀏覽器 localStorage 保存。
- 全部資料夾與檔名使用英文，避免 Windows 解壓縮亂碼。

## 部署

將此資料夾內容覆蓋 GitHub 專案根目錄後提交。GitHub Pages 使用 `main / root`，Actions 第一次執行會建立各資料分支。

詳細限制與替代方案見 `docs/LIMITATIONS.md`。
