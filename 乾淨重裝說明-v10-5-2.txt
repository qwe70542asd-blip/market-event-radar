乾淨安裝
1. 解壓縮本 ZIP 到桌面。
2. 開啟原本 market-event-radar 資料夾並顯示隱藏項目。
3. 保留 .git 資料夾；其他舊檔案與資料夾全部刪除。
4. 把本包資料夾裡的內容複製到 market-event-radar 根目錄。
5. 確認 index.html 直接位於根目錄。
6. GitHub Desktop：Commit to main → Push origin。
7. GitHub Actions 手動執行市場、事件、新聞、法人更新工作流程。
8. 第一次開啟會清除舊快取並自動重新載入一次。
