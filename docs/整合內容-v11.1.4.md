# v11.1.4 修正內容

## 錯誤原因

GitHub Actions 執行 pandas `read_html()` 時，MOPS 回傳的部分 HTML 無法由 lxml 解析。
pandas 會改用 html5lib，但舊版 requirements.txt 沒有安裝 html5lib，因此所有最近四季 MOPS 表格都解析失敗。
最後 1595 沒有 EPS，回歸驗證依設計停止發布。

## 修正

- 新增 `html5lib>=1.1,<2`。
- 新增 `read_html_tables()`：
  1. 優先使用 lxml。
  2. lxml 失敗時使用 html5lib。
  3. 兩者都失敗才回報表格解析錯誤。
- 新增 dependency preflight。
- Workflow 在資料更新前顯示 pandas、lxml、html5lib 版本。
- 保留全市場覆蓋稽核與 1595 EPS 回歸檢查。
