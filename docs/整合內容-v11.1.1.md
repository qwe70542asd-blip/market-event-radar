# v11.1.1 修正內容

## 畫面

- 移除 `.noise` 點狀背景裝飾。
- 投資組合卡片改為自動換行，不再出現桌機水平捲動。
- 新聞卡高度縮短，摘要限制兩行。
- 股票／ETF 詳情頁的 Hero、指標卡、雷達圖、產業排名與資料卡縮小空白。
- 1400px 以上五欄、一般桌機自動分欄、手機單欄。

## 新聞

- 舊資料中的 `twse.com.tw/rwd/zh/news/newsDetail/...` 會在前端轉成可閱讀的 `/zh/news/newsDetail/...`。
- 新聞排程會讀取證交所 detail API，若有官方 PDF 就直接保存 PDF 連結。
- 新增證交所 OpenAPI 新聞來源，並保留 Yahoo、鉅亨、MoneyDJ、券商／投顧來源。
- 來源失敗時保留上次成功資料。

## 股票分析

每日資料排程新增：

- 上市／上櫃正式證券主檔。
- 上市／上櫃本益比、殖利率、股價淨值比。
- 各業別綜合損益表。
- 各業別資產負債表。
- EPS、ROE、毛利率、營業利益率、淨利率、負債比、流動比率。
- 同產業 EPS、ROE、估值分位與穩健度排名。

所有有官方申報資料的股票都會產生分析；欄位不適用或官方尚未發布時保留空值。
