# v11.4.50 — major cleanup and correctness refactor

## Correctness
- Date-only central-bank/news events no longer display an invented 09:00 time.
- Homepage event labels distinguish exact-time events from date-only events.
- Foreign institutional direction combines TWSE + TPEx and refuses to present a stale chip date as today's direction.
- Breaking labels require an actual breaking-event signal, not only a heuristic score.
- Low-score photo stories no longer enter the major-information block merely because they have an image.
- EU and UK are selectable calendar regions.
- K-line fallback copy no longer promises a crosshair that is not loaded.

## Performance and resilience
- Homepage uses events-index.json; full events.json is lazy-loaded only outside the compact calendar window or by event detail pages.
- Service worker precaches a core shell; optional assets use best-effort caching so one missing seed cannot block installation.
- Service-worker registration is not pinned to an old patch version.
- Runtime Worker compatibility is schema-gated instead of frontend-patch-version gated.

## Release hygiene
- Python producers read VERSION.json through scripts/common.py.
- Update workflows include VERSION.json in push paths so live branch channel metadata cannot remain on an older app release.
