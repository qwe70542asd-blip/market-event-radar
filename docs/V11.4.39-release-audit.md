# v11.4.39 release audit

Target: stable rebuild of the TPEx / data-verification contract layer without removing existing site features.

Release acceptance criteria:

1. Data Verification handles ETF-first and stock-first ordering without uninitialised variables.
2. TPEx day-trading parser accepts the observed official OpenAPI schema and refuses partial core rows.
3. TPEx dividend eligibility does not confuse monetary fields with meeting dates.
4. Release verification runs deterministic application tests before live external-source checks.
5. External TPEx outages do not masquerade as application regressions; reachable schema mismatches remain blocking.
6. No audio, temporary, nested repository, cache, or helper artifacts are included in the release ZIP.
