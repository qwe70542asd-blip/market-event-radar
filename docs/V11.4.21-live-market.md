# v11.4.21 即時行情部署

網站本身仍可使用 GitHub 資料分支；盤中每分鐘檢查則使用 `edge/market-live-worker.js`。

1. 建立 Cloudflare Worker 與 KV namespace。
2. 以 `edge/wrangler.toml.example` 建立 `wrangler.toml`，填入 KV ID。
3. 部署 Worker。
4. 將 Worker 網址填入 `assets/runtime-config.js` 的 `liveMarketEndpoint`。

Worker 盤中每分鐘只更新當時開盤的台灣、日本、韓國或美國市場；每 15 分鐘執行完整健康檢查。網站開啟期間盤中每 60 秒讀取一次，休市期間每 15 分鐘讀取一次。GitHub Actions 保留作為五分鐘級備援與歷史封存。
