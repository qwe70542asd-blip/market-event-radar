# Market Event Radar v11.4.41

## Correctness hardening and source integrity

v11.4.41 closes the data-quality gaps found after the v11.4.40 live rollout without fabricating unavailable upstream data.

- TPEx company dates are normalized from Gregorian/ROC formats and sanity-checked; an establishment date after listing or in the future is rejected before fallback merge.
- TPEx dividend-plan parsing accepts the live legacy shareholder-meeting header `股東會日期配盈餘/待彌補虧損(元)` only as an exact official date field, while other monetary-looking fields stay excluded.
- TWSE market day-trading totals are aggregated from official TWTB4U per-security volume/buy/sell fields. Percentages are never invented when the official source does not supply them.
- TPEx institutional-amount parsing tolerates current Chinese/English schema variants and remains fail-closed when the official summary is unavailable.
- Financial verification no longer labels different/unknown financial reporting bases as conflicts. Point-in-time PE/PB/yield comparisons remain comparable.
- Individual metric badges use the metric's own verification result instead of the entire metrics-group result.
- MOPS dividend-history retries use a short circuit breaker after broad source failures and report aggregated samples rather than flooding the channel with repeated warnings.
- Media health distinguishes direct-source success from history-fallback success, so a 403/blocked live publisher is displayed as degraded rather than healthy.
- PWA network-first requests fall back to cached content on non-2xx HTTP responses as well as network exceptions.
- Diagnostic artifact upload uses the current Node-24 action major.
