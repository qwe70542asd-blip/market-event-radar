# v11.4.27 發布前自我檢查與整改紀錄

## 本版整合整改

- 法人彙總卡：上市外資、投信、自營商、合計全部明確顯示「張」，正數標示買超、負數標示賣超，並註明 1 張 = 1,000 股。
- 投資組合：新增股票／ETF 代碼與名稱即時搜尋選單；支援代碼前綴、名稱、鍵盤上下鍵與 Enter、觸控選取；選取後自動帶入名稱；不存在的標的不允許加入。
- 今日產業強弱：將 TWSE／TPEx 產業數字代碼先轉成中文，不再把 26、28 等裸代碼直接顯示給使用者；同一股票在榜單去重。
- 首頁精選重大資訊：改為 12 欄自動填滿式 Grid，2～6 張卡片均會平均使用可用寬度，避免右下角大片空白。
- 首頁時效：精選新聞限定最近 24 小時，重大事件限定今日、明日、後日；舊新聞保留於歷史清單，不再拿來補首頁空位。
- 新聞圖片：即時新聞與歷史回補先合併，再統一解析原文；Google News 先解析回原始文章；依序檢查 OG、Twitter、JSON-LD、srcset、文章主圖；排除 Logo、預設 OG、placeholder、icon、banner 與小圖；保存多個候選 URL，前端逐一重試後才使用本站分類備援圖。
- 日經 225：已加入 Nikkei 官方 Daily Data CSV 作「已完成交易日」的 OHLC／收盤交叉驗證；盤中仍使用 Yahoo 同交易日即時資料，兩者日期不一致時不得混用。
- 六大指數：台灣加權、道瓊、NASDAQ、費半、S&P 500、日經 225；KOSPI/KOSDAQ 不再作為首頁指數卡。
- 資料保護：行情驗證失敗時保留最後一次通過驗證的資料，不以混期或可疑數值覆蓋。

## 15 分鐘 K：已知非阻擋問題

**15 分鐘 K 線本版先跳過線上通過判定。**

原因：15 分鐘 K 依賴 Yahoo／Edge Worker 的外部執行環境，本機與離線 release 測試無法證明部署後一定可取得，因此 v11.4.27 明確列為**非阻擋**項目，不得把「未測」宣稱成「已通過」。

部署後必須另外檢查：六個指數逐一選擇「15分」，確認至少可取得兩根有效 K 棒、來源時間為目前交易日，而且 OHLC 屬於同一交易時段。若來源失敗，前端必須顯示「15 分鐘資料暫時無法取得」，**不得偽造 K 棒**；日 K、5 分、30 分、1 小時等已取得資料可繼續使用。

## 即時行情部署依賴

`assets/runtime-config.js` 的 `liveMarketEndpoint` 若仍為空字串，代表 Edge Worker 尚未接入。此狀態下 GitHub Actions 是行情更新備援，不能宣稱每 30～60 秒真正即時。部署 App 前需設定 Worker HTTPS endpoint，再執行盤中驗證。

## 發布門檻

本地必須通過：Python／JavaScript 語法、單元與靜態測試、公開資料嚴格驗證、GitHub Actions YAML 解析、HTTP 頁面與資源 smoke test、ZIP 解壓後重測、敏感資訊／音訊檔掃描。外部 15 分鐘 K 與 Worker 真即時更新則明確列入部署後驗證，不隱藏、不虛報。
