# v11.4.12

## Homepage integration

- Balanced 50/50 asset summary and live market snapshot.
- Full-width calendar below the summary row.
- Newly announced dates placed directly above the calendar.

## Dual calendar modes

- Market mode excludes dividend events and provides region, event type, impact and sector filters.
- Dividend mode only shows dividend events and provides dividend type, asset class and amount filters.
- Mode-specific day dialogs and month summaries.
- Last selected mode is persisted in localStorage.

## Date announcement navigation

- New dates and changed dates are sourced only from `events.json` announcement metadata.
- A calendar action switches to the correct mode and target month.
- Changed events display both current and previous dates.
