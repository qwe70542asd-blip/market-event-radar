# v11.4.35

## Remaining pipeline corrections after v11.4.34

- **TPEx historical ex-right/ex-dividend** now accepts the documented generic `代號` / `名稱` / `權或息` / `現金股利` / `每仟股無償配股` fields instead of assuming MOPS-style company headers. The documented `每仟股無償配股` value is converted from shares-per-1,000-shares to a per-share ratio before it is exposed as `stock_dividend_ratio`.
- **TPEx dividend decisions** now normalize list/table payload shapes, accept the current long board-decision header (`現金股利經董事會決議、增資配股經董事會擬議日期`) and decorated date values, and can fall back to the separate official TPEx material-information feed when the legacy dividend table returns rows that cannot produce a current-window event.
- **TPEx day-trading** now parses ROC dates directly, selects the latest valid session from the official market-aggregate series, exposes buy/sell amount ratios, and explicitly marks the scope as `market-aggregate`. The updater no longer fabricates per-security day-trading rows from an aggregate endpoint.
- **Data verification release barrier** waits for `live-tw-market` to reach v11.4.35 on release-code pushes before restoring source channels and publishing verification, preventing the verification job from racing ahead of the market-core job.
- **BLS 403 fallback** adds a bundled, explicitly verified 2026 schedule snapshot transcribed from official BLS release schedule pages. It is used only when all live official BLS calendar paths are blocked; it never extrapolates dates beyond rows listed in the snapshot.
- **BLS Productivity tracking** distinguishes preliminary and revised Productivity and Costs occurrences so the two releases for one reference quarter cannot collapse onto one tracking key.

v11.4.35 intentionally leaves already-correct v11.4.34 global-market session handling, Taiwan turnover history, ETF classification, stock basics, release Chromium gate, and TPEx institutional/margin parsing unchanged except for the version stamp.
