# v11.4.51 — Full Event Authority Regression Fix

## Critical fix
The v11.4.50 compact `events-index` optimization is removed. The homepage calendar and date alerts again load the authoritative `live-events/events.json` archive.

The complete archive was never deleted; v11.4.50 simply stopped reading it on the critical path.

## Preserved v11.4.50 improvements
- 1 large + 3 small major-information layout with equal total height
- date-only event display without invented 09:00 time
- stricter breaking-news label
- TWSE + TPEx foreign-flow/date guard
- EU / UK calendar filters
- resilient service-worker installation
- schema-gated Cloudflare Worker compatibility
- midnight day rollover

## Regression rule
Future releases must not replace `events.json` with a smaller event dataset unless that dataset is proven to be generated from the restored authoritative archive and published atomically in the same live channel.
