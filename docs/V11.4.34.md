# v11.4.34

## Data-pipeline corrections

- Global-market validation now compares exchange-local `market_at_local` with the exchange session date instead of comparing the Taiwan display date across time zones.
- TPEx dividend-plan and historical ex-right/ex-dividend parsers accept punctuation/schema variants through semantic field matching.
- Taiwan turnover parsing accepts table field descriptors and broader official amount/date field variants while retaining fail-closed completeness rules.
- Taiwan ETF classification restores the live official asset master before market refresh and uses it as a verified fallback when an exchange fund endpoint changes schema.
- Taiwan chips now attempts official TPEx institutional, margin and intraday-trading channels in addition to TWSE; Yahoo remains reference fallback only.
- Invalid weekend/future dates are removed from nested chip source/history rows.
- Data verification also runs on relevant release-code pushes, while the hourly schedule remains best-effort.

External sources may still return 403, empty or changed schemas. Those failures stay visible and last-known-good data is retained rather than fabricated.
