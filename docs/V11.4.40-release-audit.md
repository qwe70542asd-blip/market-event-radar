# v11.4.40 release audit

Target: integrate the v11.4.39 self-check findings without regressing the stable TPEx/live-data contract core.

Release acceptance criteria:

1. Two-character company aliases do not match ordinary prose collisions such as `至上` inside `截至上午`, while real short company mentions remain detectable with adjacent market context.
2. `毛利率` / `淨利率` / `營益率` do not trigger the central-bank interest-rate category; explicit Fed/央行/rate language still does.
3. Push-triggered Data Verification waits for all isolated core channels to publish v11.4.40 before producing the verification snapshot.
4. TWSE institutional/margin/day-trading parsers accept the verified market date when row-level dates are absent and preserve last-known-good data on upstream failure.
5. Market institutional summary cards render both net lots and official net amount for TWSE and TPEx when available. No amount is estimated from price × lots.
6. TPEx issued shares may be derived only from official paid-in-capital/par-value fields with explicit provenance.
7. Dividend reference history never overwrites an official match; ex-date is the strongest cross-source identity, and same-year multiple distributions remain separate.
8. Verification text normalization removes harmless typography/legal-name differences without suppressing genuinely different values. Active ETF no-tracking-index semantics do not become false conflicts.
9. PWA same-origin static files are usable from the installed cache; live data remains network-first.
10. Missing Cloudflare secrets produce an explicit deployment skip warning rather than a red false-regression signal.
11. Release verification retains deterministic data/tests/HTTP/Chromium/live-contract gates.
12. No audio, temporary, nested repository, cache or build-helper artifacts are included in the release ZIP.


## Existing non-blocking market-history policy

The prior release policy remains unchanged: **15 分鐘 K** history is a **非阻擋** item verified **部署後** from the live data channel. Missing historical intervals must remain unavailable and **不得偽造** candles from unrelated daily data.
