# v11.5.1 Runtime Stability / Conflict Audit

## Release contract

v11.5.1 is a complete repository replacement. It contains the production project directly at archive root and does not require a patch, updater, overlay or generator.

## Homepage boot path

The compact live-data architecture from v11.5.0 remains authoritative. v11.5.1 additionally bounds first paint work:

- `index.html` loads one `data/home-bootstrap-seed.js` static fallback bundle instead of 19 individual seed requests.
- External homepage scripts are deferred.
- Live JSON requests are deduplicated by canonical URL while in flight.
- First-paint branch fallback uses two mirrors; the wider fallback ladder is reserved for later refreshes.
- News sources start progressively with one worker and a short delay/stagger.
- focus/visibility market refreshes are throttled.
- stale guard shares normal boot requests and does not force-refresh until 15 seconds after boot.
- legacy browser-storage cleanup runs after load during idle time rather than synchronously scanning all channels.

## Service Worker / cache contract

- Cache namespace: `market-event-radar-v11-5-1`.
- Activation removes older `market-event-radar-*` caches.
- Static versioned assets use cache-first.
- Navigation and live data JSON use bounded network-first with current-cache fallback.
- Canonical cache keys remove only transient `t` and `_` query parameters; the `v` build parameter is retained.
- `ignoreSearch:true` is prohibited for runtime asset fallback because it can mix build versions.
- SW registration runs after page load/idle and never reloads the page from `controllerchange`.

## Version source of truth / Actions

`VERSION.json` is the release source of truth. Workflows that validate payload or deployment version resolve it from that file instead of embedding `v11.5.1` in assertions or deployment commands. Active bundled data metadata is normalized to the same release version.

## Existing architecture preserved

- compact frontend contracts: `home-assets.json`, `home-events.json`, `tw-market-compact.json`, `tw-chips-compact.json`;
- full archives remain background / history / on-demand fallback data, not primary homepage boot dependencies;
- 00-99 two-digit asset detail shards;
- 24 isolated live branches with one publisher each;
- data freshness, partial/degraded states and cross-source conflicts remain fail-closed rather than being displayed as fresh;
- unknown numeric industry taxonomy cannot render directly as an industry label.
