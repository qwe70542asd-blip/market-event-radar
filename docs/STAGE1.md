# v11.3.0 Stage 1

本階段只處理已確認的錯誤與分類問題，不包含第二、第三階段的新功能擴充。

## 已完成

- 全球市場移除 NVIDIA，新增 KOSPI、KOSDAQ、VIX、美國 10 年債殖利率、美元指數、美元兌新台幣與美元兌韓元。
- 台股 ETF 分類改用官方基金名單，權證及其他衍生商品標記為 `other`，不進入股票或 ETF 排行。
- 修正 `null`、空字串被 JavaScript 誤判成數字 0。
- 新聞移除首頁、搜尋頁、分類頁、下載頁與沒有具體內容的公告入口。
- 第一階段曾使用 Google News 轉址過濾；v11.4.15 已改為各媒體直接來源，不再使用此單一路徑。
- 單一公司的普通公告歸入個股公告，不列入市場級重大資訊。
- 公告標題優先整理為「代碼＋公司＋事件＋日期／數字」；無法整理者直接排除。
- 日曆資料加入台北本地日期，前端與資料更新器都會去除重複事件。
- Service Worker 快取更新為 `11.3.0-stage1`，避免瀏覽器繼續顯示舊版。

## 尚未包含

- 重大事件下方的相關新聞配對。
- 個股完整財務指標與最近 12 季財報。
- 公告卡片的欄位化摘要與全文展開版面。
- 真正使用模型 API 的文章摘要。

以上保留至後續階段。
