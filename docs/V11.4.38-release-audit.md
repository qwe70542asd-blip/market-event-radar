# v11.4.38 Release Audit

## Scope

This release is deliberately limited to core data correctness and observability. It does not change the TPEx day-trading or dividend-plan parser before the live diagnostic evidence is captured.

### Core fixes included

- News identity now prefers canonical article URL, so publisher headline edits on the same URL do not create duplicate cards.
- Numeric amounts are no longer accepted as stock codes merely because the word「股票」appears nearby; known ambiguous aliases such as「時報」「及成」require company context.
- Generic publisher artwork such as Google preferred-source illustrations, CNA `pic_fb`, and line-ad images are rejected before article-image selection.
- ETF issuer / manager / benchmark verification uses text-aware comparison rather than numeric conversion.
- TWSE ETF benchmark parsing stops before「投資策略」and normalizes active-ETF「無」to「不適用」.
- Data verification records per-symbol timestamps when the underlying row exposes one, while retaining channel snapshot timestamps separately.
- Portfolio NT$ totals convert supported foreign currencies through the available USD/TWD cross rate and fail closed when a required FX rate is missing instead of summing mixed currencies directly.

## TPEx diagnostic contract

`Diagnose TPEx live schemas` remains included and captures live response HTTP status, schema, representative public rows, date detection and current parser decisions. The TPEx production parser is intentionally unchanged until that artifact is reviewed.

## Release gate

The TPEx live-source contract remains blocking. A red gate is preferred to a false green result when the official source returns rows that the parser cannot recognize.

## Validation

- Python compileall
- JavaScript `node --check`
- Shell syntax
- strict public-data validation
- pytest regression suite including v11.4.38 core cases
- HTTP app-shell integration

## Existing post-deploy checks

**15 分鐘 K** remains a **部署後** observation and is **非阻擋** for the static release package. If the upstream channel has not produced a verified 15-minute bar, the UI must report that state and **不得偽造** candles or timestamps.
