# Market Event Radar v11.4.40

## Data integrity, institutional amounts and release synchronization

v11.4.40 focuses on correctness and resilience rather than adding unrelated surface area.

- News entity extraction now treats every two-character CJK company alias as ambiguity-prone and requires adjacent market/business evidence.
- Central-bank/rate classification no longer treats stock metrics such as 毛利率、淨利率、營益率 as interest-rate stories.
- Data Verification waits for all isolated core data branches to reach the release version before a push-triggered verification snapshot is published.
- TWSE chip adapters use verified-session fallback dates, date-specific report requests, JSON/BOM tolerance and retry/backoff.
- TWSE and TPEx market institutional cards can carry both net lots and official net amount; missing amount data remains unavailable rather than estimated.
- TPEx issued shares can be calculated from official paid-in-capital/par-value fields when an explicit issued-share field is absent.
- Dividend history merges Yahoo dividend events as reference-only backfill while TWSE/TPEx/MOPS official rows remain higher priority.
- ETF verification normalizes harmless text variants and skips tracking-index conflict checks for active ETFs whose official tracking index is not applicable.
- Same-origin static PWA assets use cache-first behavior; navigation and live data remain network-first.
- Cloudflare deployment is an explicit success-with-warning skip when required secrets are absent; it never claims that a worker was deployed.
- GitHub checkout/setup-python actions use Node-24-compatible major versions.
