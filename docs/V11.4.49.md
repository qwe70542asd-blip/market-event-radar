# Market Event Radar v11.4.49

Full-replacement reliability release.

## Key changes
- Ships as a complete clean repository payload rather than another overlay.
- Removes old deletion manifests and old homepage override CSS by construction.
- Adds exact 2026 policy-decision dates from official BOJ, ECB, BOE, Taiwan CBC and BOK schedules.
- Keeps those central-bank entries date-only when the official schedule does not state an exact release time; no invented clock times.
- Fixes homepage focus-industry recency: prefer the last 24 hours, fall back only to 72 hours.
- Tightens market-structure detection so a bare mention of TWSE/TPEx/FSC is not enough.
- Keeps true breaking news for up to 48 hours and systemic/policy/market-structure news for up to 72 hours.
- `publish_data_branch.sh` now reads the release version from `VERSION.json` instead of publishing a stale v11.4.46 channel marker.

## Production safety
Cloudflare Worker hostname allowlisting, KV schema checks, native rate limiting, read-only routes, strict CSP, no-referrer, immutable Action pins and fail-closed production authorization remain unchanged.
