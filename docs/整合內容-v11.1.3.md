# v11.1.3 整合內容

## 每分鐘行情

- 首頁台灣加權與台灣櫃買指數，每 60 秒抓取 TWSE MIS。
- 首頁投資組合、完整投資組合頁及單一股票頁，每 60 秒抓取持有標的。
- 指數使用 `tse_t00.tw` 與 `otc_o00.tw`。
- 上市股票使用 `tse_<代碼>.tw`，上櫃股票使用 `otc_<代碼>.tw`。
- TWSE MIS 瀏覽器直連失敗時，退回 GitHub live-data。
- 完整市場排行維持 GitHub Actions 每 5 分鐘更新。

## 全市場股票財務

資料來源：

- TWSE／TPEx 上市上櫃正式證券主檔。
- 上市／上櫃綜合損益表。
- 上市／上櫃資產負債表。
- 上市／上櫃 EPS 統計。
- 營益分析。
- 本益比、殖利率、股價淨值比。
- 月營收。
- 股利分派。
- MOPS 最近四季歷史彙總表。

處理方式：

1. 建立全部上市、上櫃股票清單。
2. 讀取當期 OpenAPI。
3. 讀取最近四季 MOPS；最新季度未申報時使用上一個已公布季度。
4. 依公司代號合併損益、資產負債、估值、營收與股利。
5. 計算 EPS、ROE、毛利率、營益率、淨利率、負債比及流動比率。
6. 計算同產業 EPS、ROE、估值分位與穩健度排名。
7. 產生 asset-coverage.json 全市場覆蓋報告。
8. 驗證股票總數、覆蓋率與 1595 EPS；失敗不發布。

## 覆蓋稽核頁

`coverage.html` 顯示：

- 全部股票數。
- 完整、部分、缺漏數。
- 各欄位覆蓋比例。
- 缺漏股票及缺少欄位。
- 可依代碼或名稱搜尋並進入股票頁。
