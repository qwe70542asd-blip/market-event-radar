# Market Event Radar v11.4.47

## Homepage
- Moves the dual-mode event calendar ahead of the six-index K-line monitor.
- Replaces the five-wide feature strip with four compact square quick-navigation tiles.
- Desktop navigation floats at the left edge while scrolling; smaller layouts become a sticky horizontal strip.
- Reduces the height of the selected major-information lead story and side stories.

## Live-market Worker
- Removes the `live-runtime` branch dependency from browser startup and deployment.
- Browser accepts only the exact HTTPS host `market-event-radar-live.qwe70542asd.workers.dev` and requires a matching `/health` identity contract.
- Introduces `schema_version = market-snapshot-v2`.
- KV snapshot key is now `snapshot:market-snapshot-v2`; K-line cache keys also include the schema version.
- A missing snapshot performs a full six-index refresh even outside market hours, avoiding empty first-deploy caches.
- Rate-limit keys include a SHA-256-derived requester key plus route/symbol/interval, preventing one client from exhausting the shared route bucket.

## Production gate
- Readiness validates schema compatibility instead of requiring cached snapshot app-version equality.
- Deployment workflow is read-only in GitHub and no longer publishes `live-runtime`.

## Taiwan market validation
- Turnover history and quote snapshots are treated as separate verified channels.
- A newer verified turnover session no longer fails merely because a complete quote snapshot was retained from an older day.
- `history_end` and `quote_trading_date` are still cross-checked for internal consistency.

## Upgrade
Run `CLEAN-REPO.cmd` once after overlaying the package so previous release manifests are removed before CI.
