# v11.4.35 release audit

## 必查項目

1. TPEx historical ex-right/ex-dividend parser 必須支援官方文件中的 `除權息日期`、`代號`、`名稱`、`權或息`、`現金股利`、`每仟股無償配股`，不得因只認 MOPS company headers 而把非空來源解析成 0 件；`每仟股無償配股` 必須先除以 1000 再寫入 per-share `stock_dividend_ratio`，不得把每仟股數字誤標成比例。
2. TPEx dividend plan parser 必須接受 `公司代號名稱`、分離式公司欄位、全形標點、decorated ROC/Gregorian date，以及 `現金股利經董事會決議、增資配股經董事會擬議日期`。
3. TPEx dividend legacy table 若非空但無法產生 current-window event，可使用獨立的官方 TPEx 每日重大訊息作為「股利決議日期」備援；不得以今天日期或推測日期補值。
4. TPEx day-trading OpenAPI 在本版按官方 market-aggregate 口徑處理；必須選擇 verified trading date 以前最新有效 session，不得把 aggregate row 偽造成個股當沖資料。
5. ROC 日期 (`115/08/07`, `1150807`) 與 Gregorian 日期都必須正規化成 `YYYY-MM-DD`，週末／未來日期仍要 fail closed。
6. release-code push 時 data verification 必須等待 `live-tw-market` 版本達到 v11.4.35；逾時應 fail，不得讀舊版 market snapshot 後仍發布綠色驗證。
7. BLS live ICS、per-release pages、annual calendar 全部遭 403 時，才可使用 `data/bls-official-schedule-2026.json`；snapshot 只能包含逐筆由 BLS 官方 schedule 驗證過的日期，不得推算下一次發布日。
8. BLS snapshot event 必須保留原官方 schedule URL、`schedule_snapshot_verified_at` 與 `date_basis=BLS official 2026 schedule bundled snapshot`，讓 UI／稽核能區分 live fetch 與 fallback。
9. Productivity and Costs preliminary / revised 同季事件不得共用一個 tracking key。
10. v11.4.34 已修好的 global market exchange-local session、TWSE+TPEx turnover completeness、stock basics numeric industry、nested chip dates 與 Chromium runtime gate 不得回歸。
11. `scripts/cleanup_repo.py --check` 必須通過；release tree 不得含巢狀 repository copies、音訊、暫存檔、`__pycache__` 或 `.pyc`。
12. 15 分鐘 K 線仍屬部署後非阻擋資料；沒有可信資料時不得偽造。

## 部署後確認

- `live-events` 的 `tpex-exdiv-history` 不再出現「rows returned / parser 0」；若來源真的沒有 current-window rows，message 必須說明而不是猜資料。
- `tpex-dividend-plan` 應直接解析官方股利表；若 schema 再變，官方 material fallback 應至少提供已確認的股利決議日期，且 message 需清楚標示 fallback。
- `live-tw-chips.markets.tpex.day_trading_date` 應等於最新 verified trading date 或較早的最新官方 session，並帶 `day_trading_scope=market-aggregate`。
- release push 後 `live-data-verification` 的 `tw_market` source snapshot 必須讀到 v11.4.35，而不是先於 market-core 完成。
- GitHub Runner 即使持續收到 BLS 403，BLS source 應能由 bundled official snapshot 保持可用，且不得製造「今日新公布日期」洪水。
