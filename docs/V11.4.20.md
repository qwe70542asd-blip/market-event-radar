# v11.4.20 strict data correctness

- Daily index change uses adjacent daily sessions, never chart-range previous close.
- Material-event dates are selected by labeled event fields; reporting-period dates cannot become calendar dates.
- BLS ICS has an official annual HTML fallback; BEA has primary and full-schedule parsers.
- News stock codes must exist in the official full-market master; company names use longest-match-first association.
- Company-master completeness and financial-data completeness are separate metrics.
- Invalid arithmetic, OHLC, event dates, or stock associations block publication.
