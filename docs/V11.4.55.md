# v11.4.55 — 手機儀表板與事件月曆清晰化

本版以 v11.4.54 Full Replace 為唯一母版，保留既有行情、法人、K 線、新聞、ETF、個股與資料防呆，僅針對手機可用性與首頁決策資訊做增量調整。

## 主要變更

- 移除會在手機底部額外注入的第二組 01–04 快速導覽，避免覆蓋資產、日曆與 K 線內容。
- 首頁原有 01–04 快速導覽在手機改為頁面內元件，不再固定／黏住畫面。
- App 安裝按鈕只在真的可安裝（或 iOS 可加入主畫面）時顯示，降低底部導覽擁擠。
- 新增「市場上漲熱度」：用全市場上漲家數占比呈現 0–100，並同步顯示上漲／下跌／平盤家數。
- 新增「今日風險」：依市場廣度、法人方向、成交動能與當日高影響事件做低／中／高提示；資料不足時明確顯示等待，不偽造結論。
- 新增「今日產業動能」：依產業成分股漲跌幅中位數列出強勢／弱勢 TOP 3；明確標示不等同資金淨流入。
- 事件月曆手機版不再用難辨識的彩色橫線，改成「顏色圓點 + 件數」。
- 月曆新增圖例：重大事件、經濟／央行、公司資訊、股利／除權息。
- 點日期後，手機事件明細改為底部抽屜式視窗，並先顯示高影響、經濟／央行、公司資訊件數。
- 手機保留「點日期查看…」說明，不再因響應式 CSS 被隱藏。

## 防回歸

新增 `tests/test_mobile_dashboard.py`，並將它加入 GitHub Hosted Runner 的 release verification 快速回歸集合，固定檢查：

- 不得重新注入第二組手機 01–04 導覽。
- 不得重新出現固定於底部、遮住內容的 quick nav。
- 月曆必須使用 dot/count marker，不得退回橫線 pill。
- 手機月曆提示與 bottom sheet 行為必須保留。
- 市場熱度、風險與產業動能在 live 資料升級時必須同步刷新。
