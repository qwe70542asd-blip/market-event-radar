# v11.4.32 release audit

## 必查項目

1. `scripts/cleanup_repo.py --check` 必須通過，release tree 不得保留 `scripts/.github`、`scripts/assets`、`scripts/data`、`scripts/scripts` 等巢狀副本。
2. 台股舊資料 migration 測試必須證明週末 `2026-08-08` 不會成為 `trading_date` 或成交歷史 session；verified trading date 選定後，任何較新的殘留 history row 也必須被裁掉。
3. BEA PCE 不同月份必須擁有不同 tracking key；tracking schema 升級當次不得產生整批「日期異動」，舊 recurring v1 state 必須移除。
4. BEA 表格 parser 必須保留 `Personal Income and Outlays, July 2026` 的完整 title；GDP `Third Estimate ... 2nd Quarter 2026` 必須分類成 third，不得被 reference quarter 的 `2nd` 誤導。
5. 同日 manual PCE/GDP 與官方事件只能呈現一件 canonical event；但同股票同日的股利方案、股利發放、除權、除息不得互相合併。
6. BLS 個別 schedule parser 必須支援官方 `Reference Month | Release Date | Release Time` 分欄結構；fallback 為 ICS → 個別 schedule → 年度頁，抓不到時保留 last-known-good，不得捏造日期。
7. TWSE TWT49U 必須使用 `strDate` / `endDate` 區間查詢；2026 schema 的 `權/息`、`權值+息值` 不得讓純除息誤判為除權息。
8. `tpex-exdiv-history`、`twse-material`、`tpex-material` 必須 incremental merge：舊 past archive 保留，未來同 tracking key 真改期才由 refreshed future row 取代。
9. TPEx 股利來源若回傳非空 rows 但 parser 為 0，source health 必須 warning。
10. `tw-chips` 舊 prefixed key 必須 migration，週末／未來日期不得留在 rows/history/market metadata，schema 必須為 `symbol-keyed-v2`。
11. Lightweight Charts CDN 不得阻擋 `shared.js` / `home.js`；SVG fallback 必須可獨立顯示，library late-ready 後可重新 render。
12. 手機市場事件 dialog 不重複顯示 summary + tab，同時維持約 40px 以上的主要 touch target；日期公告需使用 compact layout。
13. 大型 JSON 不得再整包寫入 persistent web storage；只有小型 market snapshot 維持 last-good 持久化。
14. 15 分鐘 K 線仍屬部署後非阻擋資料；沒有可信資料時不得偽造。
