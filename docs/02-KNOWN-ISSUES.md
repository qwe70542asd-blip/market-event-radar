## 不可用「看起來有內容」判定通過

以下情況一律算失敗：

- 有卡片但只有破折號。
- 有數字但其實是預設 `0`。
- 畫面時間一直變，但資料時間沒有變。
- 只顯示內建新聞，線上新聞仍為 0。
- Actions 顯示綠色，但 `live-data` 沒有新提交或 JSON 沒更新。
- 桌機正常，手機字體重疊或輪播跳動。
